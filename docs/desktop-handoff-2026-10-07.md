## 2. 확장 패널 UI 개편 — 승인된 설계

사용자가 추가 요청한 뒤 Claude에게 구현·검증·커밋·푸시·PR·main 병합까지 지시했다.

1. 상단 `01 준비 / 02 인식 / 03 노트` 단계 표시를 삭제한다.
2. 첫 화면에 `백그라운드 생성`과 `실시간 캡처` 선택 카드를 세로 배치한다. 카드 선택은 준비 화면 이동이며 작업 시작이 아니다.
3. 백그라운드 준비: 대상 강의/탭, 지원 여부, 과목, 노트 옵션, 저장 위치, `노트 생성 시작`.
4. 캡처 준비: 대상 탭, 화면 영역, 화면·음성 인식, 언어, 과목, `캡처 시작`.
5. 각 준비 화면에서 생성 방식 선택으로 돌아갈 수 있다. 정상인 계정·폴더 상태는 간결하게, 부족한 준비 항목만 안내한다.
6. 진행 화면은 현재 작업·강의·경과 시간·진행률·취소/일시정지 중심. 단계 번호는 제거한다.
7. 패널을 다시 열면 진행 중 작업 화면으로 복귀한다. 준비 화면을 오갈 때 선택값을 불필요하게 초기화하지 않는다. 동시 작업 제약 유지.
8. 완료 화면은 공통: `내 노트 열기`, `노트 다시 만들기`, `다른 강의 만들기`. 저장 실패는 저장 재시도와 노트 재생성을 구분한다.
9. 백그라운드 미지원 시 이유와 `실시간 캡처 설정으로 이동`을 제공할 수 있으나 자동 시작·자동 엔진 전환은 금지한다.
10. DRM·암호화 스트림·캡처 차단 감지 시 중단하며 다른 방식으로 우회하도록 안내하지 않는다.
11. 실시간 캡처에서도 기기 인식/클라우드 인식 여부를 명확히 표시하고 전송 동의를 유지한다.
12. 기존 패널 내 화면 전환과 기존 처리 엔진 재사용. 별도 프레임워크/라우터 추가 없음. 좁은 패널·팝업, 라이트/다크, 키보드·초점 접근성을 검증한다.

## 3. Claude 설계 검토 답변

Claude가 `b/sidepanel-ui-redesign`에서 아래 설계를 제안했고 Codex가 승인했다.

- 준비 DOM을 복제하지 않고 공유 컨테이너 `data-mode="bg|live"`로 분리. 숨긴 영역은 키보드 탐색에서도 제외.
- `BG_DONE`의 packageId/saved/status/notices로 완료 컨텍스트를 구성하고 공통 `stageDone` 표시.
- 백그라운드 완료 후 `다른 강의 만들기`는 화면만 초기화하며 `DISPOSE_SESSION`을 보내지 않음. 재생성은 완료 컨텍스트의 packageId 사용.
- `bgLiveBtn`은 실시간 준비 화면으로만 이동. `START_SESSION` 미호출을 회귀 검증.
- 백그라운드 진행 문구에서 단계 번호만 제거하고 상태·제목·경과 시간·진행률 유지.
- 새 선택 흐름이므로 버전 minor 변경 승인. `tools/bump-version.mjs` 사용.
- 보완 지시: `suggest === 'live'`만 신뢰하지 말고 DRM·암호화·캡처 차단 오류에서 전환 안내를 명시적으로 차단하고 테스트 추가.
