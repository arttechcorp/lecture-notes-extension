# 로컬 성능 측정과 오생성 억제 — 2단계

2026-10-03 사용자가 성능 측정, 오생성 억제, HTML 결과 보고를 요청했다. `visual-evaluation-rubric.md`의 의미 보존·재디자인 판정은 그대로 사용한다. 1단계 계획의 “프롬프트 변경 제외”는 당시 범위이며, 이번 단계에서는 제품의 검증과 프롬프트를 수정한다.

## 측정 범위

- 공개·자체 제작 이미지 12개의 실제 로컬 PP-OCRv5 실행. OCR 텍스트, 좌표, 신뢰도, 모델 초기화와 이미지별 지연을 기록한다.
- 정답·원본 SVG·의미를 드러내는 파일명은 모델 입력에서 제외한다. 원본 파일명과 정답의 연결은 실행 후 평가에서만 사용한다.
- 기존의 좌표 분산을 그림의 증거로 취급하는 규칙을 점검한다. 이 규칙의 오탐은 생성 모델의 실제 오생성률과 구분한다.
- 잘못된 후보 출력을 검증기에 직접 넣는 회귀 테스트로 차단 동작을 확인한다. 이 결과는 모델 생성 품질이나 제품 전체 정확도가 아니다.
- 수식의 OCR 문자열과 후보가 일치하더라도 원본 수식의 정확성을 증명하지 않는다. OCR 오독과 생성 모델의 추가 추측을 별도로 본다.

## 억제 원칙

텍스트 좌표, 높은 OCR 신뢰도, 유효한 인용 ID만으로 원본에 그림이 있다고 인정하지 않는다. 현재 제품 입력에는 도형·연결·계열을 검증한 이미지 영역 정보가 없으므로 검증할 수 없는 시각 출력은 보류한다. 이 제한은 정상 그림도 차단하므로 보류율과 복원 범위 손실을 함께 보고한다. 모호한 수식을 임의로 보정하거나 원본에 없는 도형을 만들지 않는다.

원본과 시각적으로 동일한 출력을 실패시키는 기존 기준은 유지한다. 이번 OCR 측정만으로 디자인 판정이나 복원 성공률을 산출하지 않는다. 별도의 복원 모델을 실행하지 않았다면 HTML에도 미측정으로 명시한다.

## 재현성과 한계

실행 환경, 소스 커밋, OCR 코드·모델·입력 체크섬을 원시 결과에 보관한다. 작은 개발용 자료이며, 같은 PC의 단일 실행 지연은 다른 기기나 긴 강의 처리량을 대표하지 않는다. 정답 주석은 AI가 시각 검토한 초안이며 독립적인 사람 검증은 남아 있다.

Exa 키는 검색용으로만 확인되었다. 외부 추론 API로 전용하지 않는다. 실제 강의 입력의 파일 저장이나 외부 전송은 이번 공개 코퍼스 실험에 포함하지 않는다.
