# 클라우드 비전 요약 경로 (유료 전용 추가 옵션) — 설계

작성일 2026-09-20 · 상태: 승인 대기

## 1. 무엇을 만드는가

기존 온디바이스 경로(PP-OCRv5 WASM + Whisper)를 **대체하지 않고**, 유료 계정이
설정에서 명시적으로 켰을 때만 동작하는 두 번째 시각 근거 생산자를 추가한다.
켜면 화면 프레임이 자체 서비스를 거쳐 멀티모달 비전 모델로 가고, 그 모델이
슬라이드를 읽어 텍스트(수식은 LaTeX, 표는 마크다운)로 돌려준다.

끄면 지금과 100% 동일하게 동작한다. 기본값은 꺼짐이다.

## 2. 속도에 대한 정직한 구분

사용자 목표는 "더 빠른 요약"이다. 이 설계는 그 목표를 두 단계로 나눈다.

| | Phase 1 (본 스펙의 구현 범위) | Phase 2 (후속 스펙) |
| --- | --- | --- |
| 프레임 공급 | 지금의 `tabCapture` 실시간 캡처 | HLS m3u8 직독 + 백그라운드 가상 seek |
| 걸리는 시간 | **줄지 않는다** (여전히 재생 시간에 묶임) | 15~30초 |
| 실제 이득 | 수식·도표 복원 품질, 로컬 WASM 연산 제거(저사양 발열·버벅임 해소) | 재생 대기 자체가 사라짐 |
| 호환성 | 모든 사이트 | 스트림 주소 접근 가능한 LMS 한정 |

**Phase 1만으로는 "빠르다"고 말할 수 없다.** 다만 Phase 2는 Phase 1이 만든
비전 근거 생산자에 프레임을 다른 방식으로 먹이는 일일 뿐이므로, Phase 1을
건너뛰면 스트림 파싱과 비전 파이프라인을 동시에 디버깅하게 된다.
Phase 1은 그 자체로 출시 가능한 품질 기능이고, Phase 2의 전제다.

## 3. 핵심 원리 — 생산자만 교체, 계약은 불변

`EvidenceStore` 아래 전 구간(중복 접기 → 청킹 → 합성 → 노트 렌더 → PDF → Vault)은
한 줄도 바뀌지 않는다. OCR이든 비전이든 결과물은 같은 항목이다:

```js
{ source: "ocr", t0, t1, text, slideId, confidence, bbox, epoch }
```

`source`에 `"vision"` 같은 새 값을 넣지 않는다. `server/index.js`의 근거 필드
검증, `lib/summary.js`의 슬라이드 접기, `lib/evidence.js`의 `restore()`, 노트
렌더가 전부 `'ocr' | 'asr'` 두 값만 안다. 새 값은 네 군데를 동시에 깨뜨리고
얻는 게 없다. 사용자에게 보이는 라벨("화면")도 동일하므로 거짓말이 아니다.

이음매는 이미 있다. `lib/session.js:5`의 `createOcrEngine()`이 돌려주는
`{ recognize(blob), terminate() }`가 그것이다. 비전 엔진은 이 인터페이스를
그대로 구현하고, `lib/session.js`의 변경은 어느 엔진을 만들지 고르는 분기
하나로 끝난다.

## 4. 유료 게이트는 서버가 판정한다

클라이언트 설정값은 "쓰고 싶다"는 의사 표시일 뿐이고, 쓸 수 있는지는 서버가
정한다. `chrome.storage`는 사용자가 마음대로 고칠 수 있으므로 클라이언트
플래그를 권한으로 쓰면 게이트가 아니다.

- `ACCOUNT_LIMITS_JSON`의 계정 항목에 선택 필드 `features: ["vision"]`을 둔다.
  없으면 빈 배열로 취급한다(= 무료 계정).
- `/v1/me`가 `features` 배열을 함께 돌려준다.
- 옵션 화면의 토글은 `/v1/me`가 `vision`을 포함할 때만 활성화된다. 포함하지
  않으면 토글은 비활성 + "유료 플랜에서 사용할 수 있습니다" 안내.
- `/v1/vision`은 요청마다 계정 `features`를 다시 확인하고, 없으면 403
  `feature_not_in_account_plan`을 준다. 클라이언트 UI를 우회해도 막힌다.

기본 계정 한도(`limitFor`의 폴백)는 `features: []`다 — 설정을 빠뜨린 계정이
조용히 유료 기능을 쓰는 실패 모드를 막는다.

## 5. 서버 `/v1/vision`

`POST /v1/vision` — `{ model, requestId, image }`

- `image`: `data:image/jpeg;base64,...` 단일 프레임. 디코드 후 1.5 MB 상한.
- `/v1/summary`의 예약·계상·락·멱등 구조를 그대로 쓴다. 이미지 입력 단가가
  텍스트와 달라 `VISION_RATES`를 별도로 두고, 예약액은 이미지 토큰 상한과
  출력 토큰 상한으로 계산한다.
- 응답 `{ text, usage }`. `text`는 20,000자 상한. 모델이 슬라이드를 못 읽으면
  빈 문자열을 주고, 클라이언트는 그 프레임을 근거 없이 넘긴다(세션은 계속).
- provider 설정은 `/v1/summary`와 동일하게 `zdr:true`, `data_collection:"deny"`,
  `allow_fallbacks:false`를 강제한다.
- 프레임은 어디에도 기록하지 않는다. 사용량 파일에 남는 건 계정·비용·요청 id뿐이다.

## 6. 호출 횟수가 비용을 정한다 — VisualGate 비전 모드

PP-OCR은 0.5초마다 돌려도 공짜지만 비전 호출은 장당 돈과 지연이다.
현행 게이트(`lib/visual-gate.js`)는 타일 변화 `accumulated > .035`만 넘으면
제출하는데, 이건 강사 커서 이동이나 판서 한 줄에도 걸린다. 그대로 두면
호출 수가 한 자릿수 배수로 늘어난다.

비전 모드의 채택 조건:

- **슬라이드 전환일 때만 제출한다** — `delta(recognized.low, current.low) > .32`
  (지금 `slideId`를 올리는 바로 그 판정).
- 전환 직후 움직임이 멎고 1.2초가 지나야 제출한다(전환 애니메이션 중간 프레임 방지).
- 판서·점진 노출은 슬라이드가 넘어갈 때 **마지막 상태 한 장**으로 흡수한다.
  중간 상태를 버리는 대신 완성된 판서를 얻는다. 손실이 아니라 교환이다.
- 세션당 호출 상한(기본 200)을 둔다. 넘으면 `gap("vision-call-limit")`을 남기고
  이후 프레임은 건너뛴다 — 세션을 죽이지 않는다.

기본(OCR) 모드의 동작은 바이트 단위로 지금과 같아야 한다. 기존
`visual-gate.test.js`가 회귀 감시자다.

## 7. 동의는 요약 동의와 별개다

`remoteSummaryConsent`는 "인식된 **텍스트**를 외부 모델에 보낸다"는 동의다.
화면 이미지 전송은 다른 범주이고, 강의 자료·사내 교육 자료의 성격상 법적으로도
같이 묶으면 안 된다. 새 `visionConsent`를 두고, `options.js`의
`wireSpeedCorrection`이 이미 쓰는 경고 모달 패턴을 그대로 따른다.

동의가 없으면 토글이 켜져 있어도 세션은 비전 엔진을 만들지 않고, 기존 PP-OCR로
조용히 돌아가지 않고 **시작을 거부**한다(AGENTS.md §2 "No auto cloud fallback"의
거울상 — 반대 방향 자동 전환도 사용자를 속이는 것이다).

## 8. 불변식 및 문구 변경 — 별도 승인 필요

AGENTS.md §2 "Memory only: 화면 캡처를 절대 외부로 보내지 않는다"와 정면으로
충돌한다. 이건 저작권 항목이 아니라 프라이버시 불변식이고, 제품 문구 세 곳에
박혀 있다. 코드보다 먼저 합의해야 할 항목:

- `AGENTS.md` §2 개정 — "기본값은 온디바이스. 사용자가 세션마다 명시적으로 켠
  비전 모드에서만 화면 프레임이 자체 서비스를 거쳐 모델에 전달된다. 오디오와
  원본 프레임 저장은 여전히 금지."
- `manifest.json`의 `description` — 현재 "화면 이미지는 기기 안에서만 처리되며
  어디에도 저장되지 않습니다"는 비전 모드에서 거짓이 된다.
- 랜딩(`landing/index.html`)과 크롬 웹스토어 등록 문구(`CHROMEWEBSTORE.md`).

셋이 어긋난 채로 스토어에 올라가면 심사 리스크다. 한 커밋에서 같이 고친다.
AGENTS.md 머리말이 "지침파일은 명시적인 지시가 있을 때만 수정할것"이라
이 항목은 사용자의 별도 승인 없이는 착수하지 않는다.

## 9. 범위 밖 (YAGNI)

- **이미지 배치 호출** — 게이트를 조이면 슬라이드 수만큼만 호출한다. 60분 강의
  40장이면 40콜이다. 지연이 실측으로 문제가 될 때 묶는다.
- **자체 OpenRouter 키 사용자** — 오퍼레이터 키는 서버 전용이라는 §2 원칙상
  비전은 서비스 경유만 지원한다. 개인 키 경로(`openRouterApiKey`)는 텍스트
  요약 전용으로 남는다.
- **오디오 외부 전송** — 음성은 로컬 Whisper 그대로다. Phase 2에서도 HLS 오디오
  세그먼트를 로컬 Whisper에 먹이지, 모델에 직주입하지 않는다.
- **모델 선택 UI** — 비전 모델은 서버 허용 목록에서 고정한다.

## 10. 검증 게이트

`tools/` 아래 비교 스크립트로 실제 공학 강의 한 편을 두 경로로 돌려 측정한다:
수식 복원율, 노트 품질, 강의당 비용, 슬라이드당 지연.

Phase 2 착수 여부는 이 수치로 정한다. 비교 문서의 "강의당 100~300원"은 그쪽
주장이지 이 파이프라인의 실측치가 아니다.
