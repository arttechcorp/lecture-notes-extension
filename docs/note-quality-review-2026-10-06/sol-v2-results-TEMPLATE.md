## 1. 진행 상태 구분 (Status Vocabulary)

실험 결과 보고서 작성 시 현재 진행 단계를 아래 4가지 표준 어휘로 명확히 구분합니다:

- `implemented`: 코드 구현 완료. 모드 배선, 스키마, 프롬프트, 도메인 로직 및 실험 도구 작성 완료 단계 (서비스 배포 전).
- `tested`: 모의 서비스 및 계약 검증 완료. 단위/합성 계약 테스트 통과 (`node --test`), 입출력 계약 및 캐시 probe 확인 단계.
- `deployed`: 서비스 배포 및 live probe 완료. Edge / Container 서버에 배포 완료되고 실 endpoint 지원 및 계정 권한이 확인된 단계.
- `quality-judged`: 블라인드 사람 평가 완료. 6개 영역(정확성·보존·구조·시각화·문항·조판)의 사람 검토와 PDF 평가가 완료된 단계.
