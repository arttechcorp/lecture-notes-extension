# Jev 사전 판단

설정의 **Jev 사전 판단 사용**을 켜면, 요약 전에 로컬에서 인식한 텍스트를 TypeSafe Jev(`typesafe/jev-1.13`)로 보내 중복 여부, 내용 역할, 중요도, 주제 전환을 판단합니다. 기본값은 꺼짐입니다. 외부 AI 텍스트 처리 동의와 OpenRouter 키 또는 연결된 운영자 서비스가 필요하며, Jev 호출에는 별도 사용량과 비용이 발생할 수 있습니다. 원본 화면과 오디오는 전송하지 않습니다. 전송된 텍스트는 추론 중 서비스와 모델에 일시적으로 노출되므로 종단간 암호화가 아닙니다.

정확히 일치하는 OCR 중복은 항상 기기에서 먼저 정리합니다. Jev는 확신도 높은 의미상 반복이나 학습 내용이 없는 진행 발화만 요약 입력에서 제외합니다. 조건, 예외, 정정, 수식, 예시, 새 정보, 낮은 인식 신뢰도 또는 애매한 판단은 보존합니다. 중요도만으로 근거를 삭제하지 않습니다. 주제 전환은 충분히 큰 원문 요약 구간을 나누는 데만 사용합니다.

판단은 시간순으로 가까운 근거 최대 3건, 180초 범위에서 이루어집니다. 캡처 공백과 탐색 구간을 넘어 비교하지 않습니다. 한 요청의 신규 근거는 최대 4건이고 전체 요청은 24,000바이트 이하입니다. JavaScript 문자열 길이 기준 1,400을 넘는 근거는 Jev 판단을 건너뛰고 기존 요약 모델에 온전히 전달합니다. 선택 사유와 중복 대상 ID는 세션 메모리의 전처리 메타데이터에 남으며, 사용자가 보관을 요청하면 기기에서 암호화한 보관본에 함께 포함됩니다.

Jev 응답이 잘못되었거나 호출이 실패하거나 취소되면 요약을 중단하고 오류를 표시합니다. 원본 세션 근거는 유지되며 다른 제공자로 자동 전환하지 않습니다. 설정을 끄면 Jev 호출 없이 기존 요약 경로를 사용합니다.
