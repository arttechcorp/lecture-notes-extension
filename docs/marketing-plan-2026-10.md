근거 자료: `README.md`, `CHROMEWEBSTORE.md`, `landing/index.html`(요금·추천 정책), `AGENTS.md`(법적 불변식).

## 0. 전제: 제품이 실제로 약속할 수 있는 것

마케팅 문구는 아래 범위를 넘으면 안 된다. 넘으면 CWS 심사 거절이나 학교·저작권 분쟁으로 번진다.

| 항목 | 실제 | 마케팅에서 주의할 점 |
| --- | --- | --- |
| 형태 | Chrome 확장(MV3) | "프로그램 설치" 대신 "크롬에 추가". 데스크톱 Zoom 앱·모바일은 지원하지 않는다. 화상회의는 **브라우저 탭에서 열린 것**(Zoom 웹, Google Meet 등)만 해당 |
| 인식 | 화면 OCR(PP-OCRv5) + 음성(Whisper), 근거 시각 연결, 수식 LaTeX·표 | 핵심 차별점. 음성 전용 경쟁사와 다른 점이 "슬라이드까지 읽는다"는 것 |
| 요금 | Free(기기 내 인식, 월 요약 한도) / Essential 24,000원(학생 14,000원, 월 600분) / Pro 28,900원 | 첫 달 무료(사전예약·추천 코드), 추천 보상 1인당 최대 2개월 |
| 백그라운드 | 유료, HLS만, 실서비스 미검증 | DRM·암호화 스트림·YouTube는 백그라운드 불가. "모든 LMS 고속 처리" 같은 약속 금지. 출시 전에는 "실시간 캡처"를 주력으로 판다 |
| 출력 | 구조화 요약·개념·문제 | "강의 녹화·다운로드·받아쓰기 전문" 표현 금지(비대체 원칙). 노트 공유·판매 유도 금지 |
| 프라이버시 | Free는 화면·음성이 기기 밖으로 안 나감 | 강점. 단 "종단간 암호화" 표현 금지 |

**이 표가 페르소나 선정 기준이 된다.** 수험생 인강(메가·해커스 등)은 대부분 DRM(Kollus 등) 플레이어라 캡처가 막힌다. 그래서 핵심 타깃에서 빼고 조건부 타깃으로 둔다.

## 1. 페르소나와 목표

우선순위: **P1 핵심** → **P2 확장** → **P3 실험**. 목표는 2026-11~2027-02(기말고사·겨울방학) 4개월 기준으로 잡았다. 수치는 출발점이라 첫 4주 실측 뒤 다시 맞춘다.

### P1-A. "사이버강의 몰아보기" 학부생 — 김서연(21, 경영학과 3학년)

- 상황: LearnUs·Moodle·e-Class 녹화강의가 학기당 4~6과목. 시험 2주 전에 1.5~2배속으로 몰아본다.
- 고통: 멈추고 필기하느라 1시간 강의가 2시간이 된다. 슬라이드 PDF는 키워드뿐이고 교수 설명은 음성에만 있다.
- 원하는 결과: "시험 범위 강의를 하룻밤에 정리 노트로."
- 플랜 적합: Free로 시작 → 시험기간에 Essential 학생(14,000원)으로 전환.
- **목표**: 가입 3,000명 / 첫 노트 생성(활성화) 60% / 학생 유료 전환 8% / 추천 계수 0.3 이상

### P1-B. "수식·회로가 많은" 이공계 전공생 — 박준혁(22, 전자공학과 2학년)

- 상황: 회로이론·신호처리·공업수학. 판서와 수식이 슬라이드에 가득하다.
- 고통: 음성 요약 앱(클로바노트 등)은 수식을 못 읽는다. 손필기는 따라가기 벅차다.
- 원하는 결과: "수식이 LaTeX로 살아 있는 노트, 몇 분 몇 초에 나왔는지까지."
- 플랜 적합: Essential/Pro(고화질 화면 인식). 품질 기대치가 가장 높다.
- **목표**: 이공계 학과 커뮤니티 10곳 침투 / 유료 전환 12%(P1-A보다 높게) / 수식 품질 불만 문의 비율 5% 미만
- 비고: 저장소의 `electric_circuits_note_example`가 바로 쓸 수 있는 데모 소재다.

### P1-C. 한국어 강의가 버거운 외국인 유학생 — Linh(23, 베트남, 국제통상 2학년)

- 상황: 국내 대학 외국인 유학생(약 20만 명 규모). 한국어 강의 속도를 못 따라간다.
- 고통: 음성만으로는 이해가 안 되고, 슬라이드 한국어 용어를 따로 번역해야 한다.
- 원하는 결과: "놓친 부분을 시각과 함께 다시 확인하고, 핵심 개념을 정리된 문장으로."
- 플랜 적합: Essential 학생. 입소문이 국가별 커뮤니티 안에서 빠르게 돈다.
- **목표**: 국가별 유학생 커뮤니티 3곳(베트남·중국·몽골) 파트너십 / 가입 800명 / 유료 전환 10%
- 선행 조건: 노트 출력 언어 옵션이 없으면 효과가 반감된다. 다국어 출력 지원 여부를 먼저 확인할 것.

### P2-D. 사내교육·자기계발 직장인 — 이도윤(31, IT기업 PM)

- 상황: 사내 LMS 의무교육, 인프런·유데미·컨퍼런스 영상, 웨비나.
- 고통: 시간이 없다. 보안 때문에 사내 영상을 외부 AI에 넣기 꺼려진다.
- 원하는 결과: "기기 안에서 처리되는 안전한 요약, 회의 전에 5분 복습."
- 플랜 적합: Pro(일반 요금, 학생 할인 없음 → 객단가 높음). 온디바이스가 결정적 셀링포인트.
- **목표**: 가입 600명 / 유료 전환 6% / ARPU 학생 대비 1.8배
- 주의: 인프런 등 일부 플랫폼은 DRM이 있을 수 있다. 지원 사이트 목록을 실측한 뒤에 문구를 쓴다.

### P2-E. 대학원생·연구자 — 최민지(27, 석사 2년차)

- 상황: 세미나 녹화, 학회 발표 영상, YouTube 강연(실시간 모드), 원어 강의.
- 고통: 영상 수십 개를 문헌처럼 정리해야 한다. 어느 시점에 무슨 말이 나왔는지 다시 찾기 어렵다.
- 원하는 결과: "근거 시각이 붙은 노트를 연구 노트처럼 쌓기."
- 플랜 적합: Pro. 연구실 단위 추천(한 명이 쓰면 랩 전체)이 잘 일어난다.
- **목표**: 연구실 단위 도입 30곳 / 추천 계수 0.5 이상

### P2-F. 실시간 온라인 수업·스터디 참여자 — 정하은(20, 전공 실시간 Zoom 수업)

- 상황: 교수가 Zoom 웹이나 Meet으로 실시간 수업을 한다. 다시보기가 없다.
- 고통: 놓치면 끝이다.
- 원하는 결과: "수업이 끝나면 정리 노트가 남아 있다."
- 플랜 적합: Free~Essential.
- **목표**: 이 사용 사례로 가입 500명. 대신 **문의·민원 0건이 최우선 목표**다.
- 주의: 타인 발언이 포함되므로 "녹음"으로 비치면 위험하다. 메시지는 "본인 학습용 정리"로 한정하고, 수업 녹음 허용 여부는 학칙을 확인하라는 안내를 붙인다. 데스크톱 Zoom 앱은 지원하지 않는다는 점을 숨기지 않는다.

### P3-G. 학습 접근성이 필요한 학생 — (청각장애·ADHD·난독)

- 상황: 대학 장애학생지원센터는 속기·대필 도우미를 쓰고 있지만 인력이 모자란다.
- 원하는 결과: "도우미 없이도 강의 내용을 시각 정보와 함께 확인."
- 경로: B2C가 아니라 **대학 지원센터 B2B·기관 라이선스**.
- **목표**: 파일럿 대학 2곳, 사례 1건 공개(사회적 신뢰 자산)

### P3-H. 자격증·공무원 수험생 (조건부)

- 유튜브 무료 강의나 DRM이 없는 인강만 해당된다. 주요 유료 인강은 DRM이라 캡처되지 않는다.
- 목표: 지원 가능 플랫폼 목록을 실측한 뒤 Go/No-Go를 판단. 그 전까지 예산 0.

## 2. 페르소나별 마케팅 전략

### 공통 원칙

- **핵심 메시지 한 줄**: "슬라이드와 목소리를 같이 읽어, 시험 직전 볼 노트를 만들어 줍니다."
- **증거 중심**: Before(1시간 강의) / After(노트 + 근거 시각 클릭) 15초 화면 녹화. 실제 강의 화면은 쓰지 않는다. 자체 제작 샘플 강의나 저작권 문제가 없는 공개 강의(CC 라이선스)를 쓰고, 그렇지 않으면 모자이크한다.
- **캘린더**: 지금(10/24)은 중간고사 직후다. **11월 중순~12월 기말고사**가 첫 전환 피크이고, **2월 말~3월 개강**이 두 번째 피크다. 겨울방학에는 P2(직장인·대학원생)에 집중한다.
- **전환 레버**: Free → (시험 D-14 알림) → 첫 달 무료 쿠폰 → 학생 요금. 추천 1명 = Essential 1개월(최대 2개월).
- **측정**: 채널·페르소나별 UTM(`utm_campaign=<persona>_<channel>`)과 앰배서더별 추천 코드. 퍼널은 방문 → 설치 → 로그인 → 첫 노트 → 유료로 본다.

### 채널별 금지선

- 에브리타임·대학 커뮤니티: 자동 게시와 다계정은 금지(약관 위반, 계정 정지). 사람이 직접 홍보게시판 규정 안에서만 올린다.
- "강의 저장/다운로드/녹화", "모든 사이트", "YouTube 백그라운드" 표현은 쓰지 않는다.
- 실제 교수·학교명이 들어간 화면은 노출하지 않는다.

## 3. Claude 기반 자동화 구상

> "clone"은 Claude(클로드)를 뜻하는 것으로 이해했다. 겸해서 **페르소나 클론(AI로 시뮬레이션한 고객)** 도 구상에 넣었다.

### 3.1 구조

```
marketing/
  personas/<id>.md          ← 1장의 페르소나 정의(단일 원천)
  briefs/<week>.md          ← 주간 캠페인 브리프
  drafts/<persona>/<channel>/  ← 생성물(승인 대기)
  approved/                 ← 사람이 승인한 것만
  metrics/<week>.json       ← 퍼널 수치(내용 없는 집계만)
.claude/agents/persona-<id>.md  ← 페르소나 클론 에이전트
.claude/skills/mkt-content/     ← 콘텐츠 생성 스킬
```

### 3.2 파이프라인

1. **페르소나 클론 에이전트**(`.claude/agents/persona-p1a.md` 등): 각 페르소나의 상황·말투·반대 논리를 시스템 프롬프트로 고정한다. 카피·광고 시안을 받으면 "클릭할지(1~5), 망설이는 이유, 믿기지 않는 문구"를 돌려준다. 싼 모델(Haiku)로 돌려 여러 안을 빠르게 거른다.
   - 한계: 시뮬레이션은 실제 고객이 아니다. 매달 실제 사용자 인터뷰 5건과 클론 응답을 비교해 프롬프트를 보정한다.
2. **콘텐츠 생성 스킬** `/mkt-content <persona> <channel>`:
   브리프 → 카피 3안(Sonnet) → 페르소나 클론 평가 → 상위안을 `humanize-korean` 스킬로 AI 문체 제거 → `ui-ux-pro-max:banner-design`으로 배너 시안 → 0장 금지선 자동 점검(금지어 grep) → `drafts/`에 저장.
3. **주간 루틴**(`/schedule`로 매주 월요일 실행):
   - 지난주 퍼널 수치를 Supabase 사용량 집계(내용 없는 메타데이터)와 UTM 리포트에서 읽어 `metrics/`에 저장
   - 채널·페르소나별 승자/패자 메시지를 판정하고 이번 주 브리프 초안 작성
   - 경쟁사 동향 웹 검색(클로바노트, 릴리스AI, 다글로 등): 가격·기능 변경 요약
4. **사람 승인 게이트**: 게시·발송은 사람이 한다. 커뮤니티 약관 문제도 있고, 대외 게시는 되돌리기 어렵다. 자동화 범위는 초안·분석·리포트까지로 한정한다.
5. **피드백 루프**: CWS 리뷰와 문의 메일(`summrizei.support@gmail.com`)을 주 1회 분류(버그/기능 요청/페르소나 신호). 새 페르소나 신호가 보이면 `personas/`에 후보로 추가한다.

### 3.3 모델 분배

- Haiku: 페르소나 클론 평가, 금지어 점검, 리뷰 분류
- Sonnet: 카피·브리프·블로그 초안
- Opus(사람과 함께): 월간 전략 조정, 페르소나 우선순위 재판정

## 4. 열린 질문

- 노트 출력 언어(영어·베트남어 등) 지원 여부 → P1-C 성패를 가른다
- DRM이 없는 주요 플랫폼 실측 목록(LMS별, 인프런, 클래스101 등) → P2-D·P3-H 문구의 근거
- 백그라운드 처리 실서비스 검증 시점 → 그 전까지 "빠른 백그라운드"는 유료 셀링포인트로 쓰지 않는다
- 결제창(`landing/billing-config.js`) 연결 시점 → 전환 캠페인 시작일
