# Summrizei 파이프라인 v2: 최종 설계·실행 계획

작성 2026-10-02 · 브랜치 `w/dev` · 대체 대상: `lib/summary.js` 중심의 v1 요약 경로

---

## 0. 한눈에 보기

- **목표**: 브라우저 탭의 영상(화면)과 음성으로 **공부하기 좋은 요약 PDF**를 만든다.
- **양식 고정 원칙**: LLM은 내용(JSON)만 채우고, 양식은 결정적 렌더러가 만든다. 노트의 층위·블록·에셋은 별도 세션에서 기획하고, 이 파이프라인은 그 결과물인 Note 스키마를 입력으로 받는다.
- **등급별 처리**:
  - **Free**는 탭을 켜 둔 채 실시간 캡처하고, 인식은 로컬(PP-OCR, Whisper)에서만 한다. 요약만 서버의 저가 LLM이 맡고, 월 한도를 둔다.
  - **유료**는 탭 없이 백그라운드에서 처리한다. 미디어 세그먼트를 직접 받아 메모리에서만 다루고, 인식은 클라우드(STT, 비전)에서 동의를 받고 한다.
- **속도**: 세그먼트·청크·섹션 단위로 병렬 처리한다. 원가는 거의 그대로이고, 유료 1시간 강의는 약 4~12분이 목표다(추정).
- **품질 장치**:
  - 수식 레지스트리: 수식을 한 번 추출해 ID로만 참조하고, KaTeX와 화면 대조로 검증한다. 실패하면 원본 크롭으로 대체한다.
  - 반복 텍스트·워터마크 제거: 역할 라벨, 문서 빈도, 업로드 전 마스킹으로 처리한다. 학번 워터마크도 이 경로로 차단된다.
  - 판단 모델(Jev류): 잡담 필터, 중요도, 도표 선택, 요약 근거 검증에 쓴다.
- **데이터 원칙**:
  - 원본 미디어는 디스크 어디에도 남기지 않는다.
  - 파생물(전사, 수식, 도표 크롭, 노트, 로그)만 기기에서 AES-GCM으로 암호화해 둔다.
  - 서버 DB에는 강의 내용이 0바이트다.
- **운영 장치**: 개발 전용 어드민(파이프라인 실시간 관찰과 로그), 사용자 로컬 암호화 로그, 진단 파일 내보내기.
- **구현 방식**: Devin이 구현 초안을 쓰고, 호스트가 테스트하고, agy가 읽기 전용으로 교차 리뷰한 뒤, Claude가 통합한다.

## 1. 배경: v1의 한계

| 한계 | 근거 |
|---|---|
| 탭을 켜 둔 채 실시간으로 재생해야만 처리된다 | tabCapture 구조 |
| 로컬 PP-OCR이 수식과 표를 깨뜨린다 | `docs/vision-bench-2026-09-20.md` (예: slide-007 `a=(1 +ζk) −1`) |
| OCR·STT 원문이 거의 그대로 LLM에 들어간다 | `lib/summary.js` 48KB 청크 |
| 노트 양식이 매번 다르다 | 스키마는 필드만 정하고, 층위와 배치는 모델에게 맡겨져 있다 |
| 워터마크와 강의명 같은 반복 텍스트가 근거에 섞인다 | OCR 경로에서 특히 심하다 |
| LaTeX가 추출·요약·렌더 단계에서 깨진다 | 자유 마크다운 비전 응답, LLM의 수식 재타이핑, `UNMANGLE` 땜질, `throwOnError:false`(`sandbox.html:284`) |
| 인식 결과가 남지 않아 다시 생성할 수 없다 | 메모리 전용 설계 |

## 2. 목표와 비목표

**목표**
- G1. 일관된 양식의 학습용 요약 PDF. 양식 정의는 노트 기획 세션의 산출물이다.
- G2. 원가를 최소로 유지하면서 인식 품질(한국어 음성, 수식, 표)을 올린다.
- G3. 유료는 탭 없이 실재생보다 빠르게 처리한다.
- G4. LaTeX를 화면에서 PDF까지 손상 없이 보존한다.
- G5. 반복 텍스트·워터마크(개인정보 포함)를 제거한다.
- G6. 암호화 강의 패키지로 다시 생성할 수 있게 하고, 보관함과 연결한다.
- G7. 개발·테스트 가시성(어드민, 로그)과 사용자 측 디버그 로그를 확보한다.
- G8. 프라이버시와 법적 안전: 저장 금지, 동의, 보호조치 존중.

**비목표 (이번 범위에서 의도적으로 제외)**
- 노트의 층위·블록·에셋 기획(별도 세션).
- 모델 직접 호스팅(`laya-serve` 포함).
- 브라우저 로컬 LLM 요약.
- 요약 전용 소형 모델(KoBART 등). flash-lite급 API가 더 싸고 한국어 품질도 낫다.
- 로컬 판단·분류 모델(Laya, GLiNER, NLI) 도입. Phase 0에서 근거가 나올 때만 검토한다. 슬라이드 용어 추출은 규칙으로 충분하다.
- 숨은 플레이어 고배속 재생, ffmpeg.wasm, 슬라이드 전환 시각 이분 탐색, 배치 API 할인 모드.
- 원본 미디어 저장·내보내기 기능.
- 결제(Paddle) 연동. 테스트 중에는 등급(entitlements)을 어드민 RPC로 수동 부여한다.
- 어드민의 모델 A/B UI(벤치 CLI로 대신한다). 모바일.
- v1 경로와의 이중 운영. 출시 전(사전 예약 단계)이므로 플래그 뒤에 구 경로를 남기지 않는다.

## 5. 아키텍처

### 5.1 구성도
```
          ┌ Free:  LiveSource  (tabCapture 실시간, 기존 캡처 코드)        ┐
[A 소스]  ┤                                                              ├→ {KeyFrame(t), AudioChunk(t0,t1)}  ※ 메모리 전용
          └ 유료:  MediaSource (HLS/DASH/mp4 직접 수신, 백그라운드)        ┘
[B 인식]   유료: AudioChunk ─병렬→ /v1/stt → Transcript    KeyFrame ─병렬→ /v1/vision → SlideDoc
           Free: 로컬 Whisper → Transcript                PP-OCR → SlideDoc(동형)
[C 정제]   반복 텍스트·워터마크 제거 → 수식 검증 → 슬라이드 병합 → 발화↔슬라이드 정렬 → Unit + 특징 → IR
[D 판정]   유료: /v1/judge (잡담·중요도·도표·근거 지지)   Free: 규칙 + Planner
[E 계획]   /v1/plan 1회: IR + Note 스펙 → Plan
[F 작성]   /v1/write 섹션별 병렬 → 블록 JSON (원본 수식은 {{F12}} 참조만)
[G 검증]   스키마·근거 ID·숫자·수식·원문 재현·근거 지지 → 실패 블록만 1회 재생성
[H 조립]   Note JSON + 수식 레지스트리 + 크롭 → 결정적 HTML → print → PDF
[저장]     강의 패키지(IndexedDB, AES-GCM) ↔ 보관함 / 단계 체크포인트 / 암호화 로그
```
두 소스의 출력 모양이 같으므로 B 이후 단계는 공통 코드를 쓴다. 소스 구현이 실제로 두 개라서 인터페이스를 두는 것이 정당하다.

### 5.2 등급별 처리 매트릭스
| 단계 | Free | 유료 |
|---|---|---|
| 소스 | LiveSource(탭 유지) | MediaSource(백그라운드). 불가능한 사이트에서는 **사용자 선택**으로 LiveSource |
| 화면 인식 | PP-OCR(로컬) | 클라우드 비전(동의) |
| 음성 인식 | 로컬 Whisper | 클라우드 STT(동의) |
| 정제 | 로컬 | 로컬 |
| 판정 | 규칙 + Planner | 판단 API + 규칙 + Planner |
| 계획·작성 | 서버 lite LLM(외부 요약 동의, 월 한도) | 서버 LLM(중급 Planner + lite Writer) |
| 수식 | OCR 기반 "미검증" 표시. 숫자 대조 실패 시 수식 줄 크롭으로 대체 | 레지스트리 → 검증 → 재판독 → 크롭 대체 |
| 도표 크롭 | 없음(부록에 고지) | 있음 |
| 보관함·로그 | 로컬 암호화, 선택 동기화 | 같음 |

- 동의를 거부하면 이렇게 동작한다:
  - 외부 요약을 거부하면 기존처럼 **인식 결과 보기**만 제공한다(`recognitionResult` 이식).
  - 유료 사용자가 클라우드 인식을 거부하면 로컬 엔진을 **명시적으로 선택**하게 한다.
  - 어느 경우에도 엔진을 조용히 바꾸지 않는다.

### 5.3 실행 토폴로지 (MV3)
| 구성요소 | 책임 | 비고 |

| 미디어 Worker | 재생목록 파싱, 세그먼트 수신, 디먹스, `VideoDecoder`·`AudioDecoder` | Worker의 교차 출처 fetch 허용 여부는 Phase 0 B2에서 확인한다. 안 되면 offscreen이 fetch하고 Transferable로 넘긴다 |

| 사이드 패널 | 진행률, 보관함 UI(얇은 RPC 어댑터, 기존 원칙) | 완료 알림은 액션 배지(권한 불필요) |
| `sandbox.html` | 결정적 렌더와 인쇄 | 검증과 렌더가 **같은 vendored KaTeX 빌드**를 쓴다 |
| 서버(무상태 프록시) | 키, 프롬프트·스키마, 과금·한도, 동의 확인 | 본문을 저장하지 않는다 |
| Supabase | 계정, 등급, 사용량 원장, 보관함 암호문 | 강의 내용은 0바이트 |
| `admin.html` | 개발 전용 관찰 화면 | 웹스토어 패키지에서 제외 |

### 5.4 데이터 계약 (모두 `schemaVersion`을 갖고, 신뢰 경계에서 검증)
| 계약 | 핵심 필드 | 수명 |
|---|---|---|
| `KeyFrame` | `t, epoch, seq, frame(VideoFrame/ImageBitmap), sample(256×144)` | 메모리. 쓰고 나면 즉시 `close()` |
| `AudioChunk` | `t0, t1, mime:"audio/mp4", bytes, overlap{head,tail}` | 메모리. 전송 후 해제 |
| `SlideDoc` | `slideId, t0, t1, blocks[{id,text,role,bbox,conf}], formulas[{id,latex,bbox,conf,status}], figures[{id,bbox,kind,title,cells?,chartSummary?,conf}], engine, model` | 패키지 |
| `Transcript` | `segments[{id,t0,t1,text,words[{w,t0,t1}],noSpeechProb?,avgLogprob?,status}], engine, model, lang` | 패키지 |
| `Unit` / `IR` | `unitId, slideId, t0, t1, slideText, speech, features{dwell,speechChars,emphasis,deixis,repeat,hasFormula,hasFigure}, judge{…}` / 순서 있는 Unit + 수식·도표 후보 | 패키지 |
| `JudgeResult` | `itemId, task, probs{label:p}, score?, model` | 패키지 |
| `Plan` | 섹션 경계, 섹션별 블록 배치, 수식·도표 참조. **블록 타입은 Note 스펙을 참조** | 패키지 |
| `Note` | 노트 기획 세션이 정의 | 패키지 |
| `Event` | `ts, jobId, traceId, spanId, parentSpanId, stage, unit, status, ms, bytes, model, costUsd, code, level, msg(≤200자, 내용 없음)` | 메모리, 로그 |
| `Package` | `meta, slideDocs, transcript, ir, judge, plans[], notes[], crops{id→blob}, boilerplate, jobState, stageCache` | IndexedDB(암호화) |

- 서버는 strict JSON Schema로 입력과 출력을 검증한다. 클라이언트는 서버 응답을 쓰기 전에 다시 검증한다.
- 패키지는 읽을 때 마이그레이션한다. 모르는 필드도 보존한다.

### 5.5 용어
- **패키지**: 강의 1개의 암호화된 파생물 묶음.
- **유닛**: 슬라이드 1장과 그 시간대의 발화.
- **IR**: 유닛들을 압축한 요약 입력. 목표 크기는 원문 토큰의 40~60%다.
- **레지스트리**: 강의 내 수식의 단일 원본.
- **lane**: 동시 실행 슬롯.

## 6. 단계별 설계

### 6.1 A. 소스

**LiveSource (Free, 그리고 유료의 수동 선택)**
- 기존 `lib/session.js`의 캡처 부분을 그대로 옮긴다: tabCapture, `frame-box.js`, `visual-gate.js`, `audio-segments.js`, preflight의 검은 화면 판정, 중첩 iframe 중단, 종료 시 drain.
- 출력 모양만 `KeyFrame`과 `AudioChunk`로 맞춘다.

**MediaSource (유료, 백그라운드)**
1. **소스 식별**
   - 사용자가 강의 탭에서 시작한다(기존 제스처와 권한 경로).
   - `webRequest`(관찰 전용, MV3 허용)로 해당 tabId의 `media`·`xmlhttprequest` 요청을 지켜보며 m3u8, mpd, mp4를 찾는다(확장자와 MIME 확인).
   - `video.currentSrc`가 `blob:`(MSE)이면 원본 주소가 아니므로 네트워크 관찰 결과를 쓴다.
   - MSE 사이트는 요청이 재생 중에 생기므로 **몇 초간 재생이 필요할 수 있다**.
   - iframe 플레이어(LearnUs 등)의 요청도 같은 tabId로 잡힌다.
2. **보호조치 감지 → 중단**(기존 불변식 "보호조치 우회 금지"를 이 경로에도 적용)
   - 대상: EME(`content.js`의 기존 감지), HLS `#EXT-X-KEY`·`#EXT-X-SESSION-KEY`(METHOD≠NONE), DASH `<ContentProtection>`.
   - 백그라운드를 중단하고 실시간 모드를 **제안**한다(묻기). EME는 실시간 캡처도 검은 화면이 되므로 완전히 중단한다.
   - 근거: 저작권법 제104조의2(기술적 보호조치).
3. **렌디션 선택**
   - 영상: **높이 720 이상 중 비트레이트가 가장 낮은 것**(슬라이드 판독에 충분). 없으면 가장 높은 것.
   - 음성: 분리된 오디오 렌디션(`EXT-X-MEDIA TYPE=AUDIO`)이 있으면 그것만 받는다.
4. **수신**
   - offscreen이나 Worker에서 `fetch(url,{credentials:"include", cache:"no-store"})`.
   - host 권한이 있으면 SameSite=Strict 쿠키도 전송된다. 서드파티 쿠키 차단·분할 환경은 Phase 0 B2에서 확인한다.
   - **Referer 검사 CDN에만** `declarativeNetRequest` 세션 규칙을 건다: `tabIds:[TAB_ID_NONE]`, `requestDomains:[CDN]`, Referer를 사용자가 보던 페이지 URL로 설정. 작업이 끝나면 즉시 제거한다. 다른 출처로 위장하지 않는다.
5. **키프레임 표본**(다운로드량을 줄이는 순서. 대상 LMS가 지원할 때만, Phase 0에서 측정)
   1. I-frame 재생목록(`EXT-X-I-FRAME-STREAM-INF`, BYTERANGE)으로 키프레임만 받는다.
   2. 서버가 `Accept-Ranges: bytes`를 지원하면 각 세그먼트 앞부분만 Range로 받아 첫 IDR을 얻는다.
   3. 둘 다 안 되면 세그먼트 전체를 받는다.
   - 디코드: mux.js(TS→fMP4) 또는 mp4box.js로 샘플을 꺼낸 뒤 `VideoDecoder`로 키프레임만 디코드한다.
   - 각 `VideoFrame`은 256×144 표본과 필요한 원본만 남기고 **즉시 `close()`**한다. 닫지 않으면 디코더 프레임 풀이 고갈돼 멈춘다.
   - `decodeQueueSize`로 백프레셔를 건다.
   - 표본마다 기존 `VisualGate`(비전 모드: 전환에서만 제출) 판정을 그대로 적용한다. 전환 시각 오차는 최대 1세그먼트다(이분 탐색 정밀화는 비목표).
6. **오디오**
   - AAC를 **재인코딩하지 않고** m4a로 재포장한다.
   - `AudioDecoder`는 VAD와 무음 경계 계산에만 쓴다.
7. **시간축**
   - 정준 시각 = 재생목록의 EXTINF 누적 + 세그먼트 안의 PTS 오프셋. DISCONTINUITY나 PTS 리셋과 무관하게 맞는다.
   - LiveSource는 기존 `currentTime + epoch`를 쓴다.
8. **저장 금지(D8)**
   - 세그먼트 버퍼는 디코드나 재포장 직후 해제한다.
   - IndexedDB, Cache Storage, OPFS, 다운로드 어디에도 원본을 쓰지 않는다.
   - 내보내기 기능을 두지 않는다.
   - 패키저 감사 규칙으로 강제한다(§20).
9. **네트워크 예의**: 호스트당 동시 수신 ≤ 4, 처리량 상한(기본 50Mbps, 서버에서 원격 조정), 429·5xx는 지수 백오프와 지터, `Retry-After` 준수. LMS의 이상 트래픽 탐지로 **사용자 계정이 제재되는 위험**을 막기 위해서다.
10. **수명**
    - 소스와 인증을 확보하면 탭을 닫아도 된다. 브라우저는 켜져 있어야 한다.
    - 작업 중에는 `chrome.power.requestKeepAwake("system")`로 유휴 절전을 막는다.
    - 인증 만료(401·403, 서명 URL 만료)가 나면 **일시정지하고 "강의 탭을 다시 열어 주세요"라고 요청**한다. 조용히 실시간 모드로 바꾸지 않는다.
11. **재개**: 작업 상태(처리한 세그먼트 인덱스, 끝난 청크 ID)를 패키지에 체크포인트로 남긴다. 다시 시작하면 남은 세그먼트만 받는다.
12. **사용 동의(D9)**
    - 백그라운드를 처음 시작할 때와 약관 버전이 바뀔 때 2항목에 각각 체크를 받는다.
    - 기록 위치: `lib/settings.js`(버전, 시각)와 서버 `profiles.consent_version`.
    - 동의가 없으면 시작 버튼을 막는다.

**방식 비교** (aside 리서치, M1 8GB, 추정치)
| 방식 | 1시간 전처리 | 추가 메모리 | 판정 |
|---|---|---|---|
| **직접 수신 + WebCodecs** | 2~10분 | 0.15~0.6GB | **채택**. 원음 그대로라 인식 손실이 없다 |
| 숨은 video + hls.js 고배속 + captureStream | 15~35분 | 0.2~0.8GB | 기각. 배속 상한 16배, 고배속에서 음소거되거나 빨라진 음성이 된다 |
| ffmpeg.wasm | 5~30분 | 0.4~1.5GB | 기각. 느리고 메모리를 많이 쓴다 |

**메모리 예산** (유료 작업 1개 기준, Phase 0에서 실측)
| 항목 | 상한 |
|---|---|
| 수신 중 세그먼트 버퍼 | 4 × ≤4MB |
| 디코드 대기 `VideoFrame` | ≤ 4개(720p RGBA 약 3.7MB/장) |
| 안정 슬라이드 원본(크롭·업로드·재판독 대기) | ≤ 8장 JPEG, 기존 64MB 이미지 예산 안 |
| 전송 대기 오디오 청크 | ≤ 3 × ≤8MB |
| 근거·IR | 기존 15MB 상한 |

### 6.2 B. 인식

**STT (유료)**
- 청크: **≤5분이면서 ≤8MB**. 경계는 목표 지점 근처의 무음에서 자르고(VAD), 앞뒤 1~3초를 겹친다. 단어 타임스탬프로 겹침 구간의 중복을 지운다.
- **VAD 게이트**: 무음이나 음악만 있는 구간은 보내지 않는다. 원가가 줄고 환각도 막힌다.
- **환각 필터**:
  - 세그먼트 품질값을 본다(Whisper 기본 임계값: `no_speech_prob>0.6`이면서 `avg_logprob<-1.0`, 또는 `compression_ratio>2.4`). Groq `verbose_json`에서 이 필드가 오는지는 Phase 0에서 확인한다.
  - 저에너지 구간의 알려진 환각 문구("시청해주셔서 감사합니다", "구독과 좋아요" 등)를 지운다.
- **용어 힌트**: 같은 시간대 슬라이드에서 뽑은 용어(규칙 기반 TF-IDF 상위)와 과목 용어집을 `prompt`로 넣는다. Whisper prompt는 **마지막 224토큰만 반영**되므로 그 안으로 자른다.
- 언어: 기본 `ko`, 설정에서 `en`. 혼용 강의는 `ko`에 용어 힌트를 더한다.

**비전 (유료)**
- 입력: JPEG, 긴 변 1280~1600px, ≤1.5MB(기존 한도).
- 알려진 반복 영역은 **업로드 전에 주변 중앙값 색으로 칠해 가린다**(§6.3).
- 응답: strict JSON `SlideDoc`. 블록 역할(`title|body|header|footer|watermark|page_number|figure_label`), 수식 LaTeX와 bbox, 도표 bbox·종류·표 셀·차트 요약.
- `mode:"reread"`: 검증에 실패한 수식·표 영역만 원본에서 2배로 잘라 상위 모델로 다시 읽는다.
- 병렬 8 lane(기존 `summary.js`의 lane 패턴).

**Free 로컬 엔진**
- PP-OCR 줄 박스를 `SlideDoc.blocks`로 바꾼다. 역할은 규칙으로 추정한다(가장자리, 크기, 문서 빈도).
- 수식 기호 밀도가 높은 줄은 `formulas[{status:"unverified", text, bbox}]`로 두고 크롭을 보관한다.
- 로컬 Whisper 출력에도 같은 환각 필터를 적용한다.

### 6.3 C. 정제 (로컬, 순수 함수)

**반복 텍스트·워터마크 제거** (`lib/boilerplate.js`)
1. 영역 제한: 플레이어 UI는 `frame-box.js`가 이미 잘라낸다.
2. 역할 필터: `watermark`, `page_number`, `footer`를 제거한다. `header`는 그 슬라이드의 제목이면 남긴다.
3. **문서 빈도 필터**:
   - 텍스트를 정규화한다(NFC, 숫자는 `#`, 공백 정리).
   - 서로 다른 슬라이드 중 **30% 이상이면서 3장 이상**에 나오면 반복 텍스트로 본다. 위치가 바뀌는 워터마크도 텍스트로 잡힌다.
   - OCR 오독에 대비해 문자 3-gram 자카드 0.8 이상이면 같은 텍스트로 묶는다.
4. 가장자리 규칙: 바깥 7% 여백의 작은 글씨가 2회 이상 반복되면 후보다. 애매한 후보는 판단 API(유료)나 보존(Free)으로 처리한다.
5. 쪽번호: 숫자만 있고 슬라이드 순서대로 단조 증가하는 경우. **표 안의 숫자는 지우지 않는다.**
6. **온라인 마스킹**: 처음 약 5장에서 위치가 고정된 반복 영역을 배운 뒤, 비전 업로드 전에 가린다. 토큰이 줄고, **학번·이름 워터마크가 서버와 노트로 새지 않는다.**
7. **과목 단위 기억**: (호스트명, 과목명)별 반복 서명을 패키지에 저장해 다음 강의 첫 장부터 적용한다. 음성의 반복 인사말·맺음말도 같은 방식으로 지운다.
8. 비파괴: 걸러낸 항목은 `selection:"filtered"`로 남긴다(디버깅과 오탐 복구용).

**수식** (`lib/formulas.js`)
- **레지스트리**: `{id, latex, bbox, conf, status: verified|reread|image|unverified}`. ID는 (슬라이드 t0, y, x) 순서로 매겨 안정적이다.
- 검증 순서:
  1. `katex.renderToString(latex,{throwOnError:true})`로 문법을 검사한다.
  2. **화면 대조**: 같은 bbox를 로컬 PP-OCR로 읽어 숫자·변수 문자 집합을 비교한다. PP-OCR은 구조는 약하지만 숫자는 강하다.
  3. 실패하면 `reread`(상위 모델 또는 수식 전용 API로 1회)를 한다.
  4. 그래도 실패하면 **크롭 이미지로 대체**하고 "원본 이미지로 표시"라고 적는다.
- 비교할 때는 공백, `\left` `\right`, `\,` 등을 제거해 정규화한다.
- 검증과 렌더는 **같은 KaTeX 빌드**(`lib/vendor/katex`, 폰트 포함)를 쓴다. 그래서 "검증 통과 = 렌더 성공"이 보장된다.
- Free: LLM이 OCR 텍스트에서 복원한 식은 "복원·미검증"으로 표시한다. 숫자 대조에 실패하면 수식 줄 크롭을 보여 준다.

**슬라이드 병합·정렬·특징** (`lib/preprocess.js`)
- 점진적 판서(연속 슬라이드에서 N의 텍스트 ⊆ N+1, 포함도 ≥0.9)는 N+1 하나로 합치고 t0는 N의 값을 쓴다.
- 정렬은 **시간 기준**(발화 중간 시각에 떠 있던 슬라이드)이 기본이다. 지시어("이 그래프", "이 표")는 현재 슬라이드의 도표에 연결한다.
  - 임베딩 API로 재배정하는 방식은 Phase 0에서 이득이 확인될 때만 쓴다.
- 특징: 체류시간, 발화량, 강조어("중요", "시험", "꼭", "반드시"), 지시어, 강의 안에서의 반복, 수식·도표 유무.
- 발화 정리: 단독 간투사를 제거하고, 반복 접기는 기존 `lib/repeats.js`·`lib/mergeLines.js`를 재사용한다.

### 6.4 D. 판정

| 과제 | 입력 → 출력 | 등급 |
|---|---|---|
| T1 발화 분류 | 문장 → {강의내용, 예시·비유, 공지·행정, 잡담} | 유료 |
| T2 유닛 중요도 | 유닛 → 점수 1~5 | 유료 |
| T3 반복 텍스트 애매 후보 | 후보 → 예/아니오 | 유료 |
| T4 도표 분류 | 도표 + 정렬된 발화 → {핵심, 보조, 장식} | 유료 |
| T5 근거 지지 | (노트 문장, 인용 근거) → 지지 확률 | 유료 |

- Free는 판정 API 없이 특징 규칙과 Planner만 쓴다.
- **보정**:
  - 라벨링 가이드(중요도 3단계 정의)를 문서로 만든다.
  - 임계값은 **2강의로 튜닝하고 1강의로 검증**한다(과적합 방지).
  - 신뢰도 곡선을 그리고 ECE를 보고한다.
  - 애매한 확률 구간(θ_low < p < θ_high)은 지우지 않고 Planner가 판단하게 넘긴다.
- 서버 `/v1/judge` 하나로 받고 배치로 호출한다. 공급자를 바꿔도 클라이언트는 그대로다.

### 6.5 E~G. 계획·작성·검증

- **Planner**: 1회. IR과 Note 스펙(블록 타입, 길이 상한)을 받아 Plan을 만든다.
  - **섹션 경계는 내용 기준**이다. 청크 경계와 무관하다.
  - 유료는 중급 모델, Free는 lite 모델(원가 상한).
- **Section Writer**: 섹션마다 병렬 실행. 해당 섹션 유닛, Plan 조각, 레지스트리 항목(읽기 전용)을 받아 블록 JSON을 만든다.
  - 원본 수식은 `{{F12}}`로 **참조만** 한다.
  - 새로 유도한 식은 `derived` 필드에만 쓰고 KaTeX 검증을 거친다.
- **Global Writer**: 섹션 결과를 입력으로 앞뒤 요약 블록을 만든다. 블록 목록은 Note 스펙에 따른다.
- **결정성**: temperature 0, 지원하는 곳에서는 `seed`, 안정 정렬, 안정 ID.
- **토큰 예산**:
  - Planner 입력 ≤ 40k, Writer 입력 ≤ 12k / 출력 ≤ 4k.
  - `finish_reason=length`가 나면 한도를 올리지 말고 **섹션을 나눠 다시 요청**한다. 현재 코드는 이 경우 재시도 없이 실패한다.
- **프롬프트 캐싱**: 변하지 않는 시스템 프롬프트와 스키마를 앞에 두고 가변 입력을 뒤에 둔다(Anthropic `cache_control`, Gemini 암시적 캐시).
- **검증기**(G):
  1. strict 스키마.
  2. `evidenceIds` ⊆ 섹션 근거.
  3. **숫자 보존**: 출력의 수치가 인용 근거에 있어야 한다(단위와 자릿수 구분자를 정규화).
  4. 수식 참조가 실재하고, 레지스트리 LaTeX를 다시 타이핑한 흔적이 0이어야 한다.
  5. 원문 연속 재현 검사(비대체성, 기존 보수적 검사 이식).
  6. 미인용 근거 비율 ≤ 0.5(기존 `MIN_COVERAGE`).
  7. 유료는 T5 근거 지지 확인.
  - 실패한 블록만 오류 목록을 붙여 **1회 재생성**한다. 그래도 실패하면 제외하고 부록에 고지한다(기존 `droppedNotice`·`uncitedNotice`·공백 구간 고지 이식).
- **Note 스펙 연동**: Plan과 Writer 스키마의 블록 타입과 길이 상한은 노트 기획 세션의 산출물을 읽어 만든다. 이 계획은 그 인터페이스만 고정한다.

### 6.6 H. 조립·렌더
- Note JSON, 레지스트리, 크롭을 받아 **결정적 HTML**을 만들고 인쇄한다(템플릿과 에셋은 노트 기획 산출물).
- 수식 블록은 마크다운을 거치지 않고 KaTeX로 직접 렌더한다(`throwOnError:true`).
- 본문 인라인 `$…$`은 자리표시자 방식을 유지하되, 실패하면 원문과 경고를 표시한다.
- 인쇄 전에 `document.fonts.ready`를 기다린다.
- `memory.md`에 적힌 결합(형광펜 `==…==`, 인용 콜아웃, 인쇄 색 토큰, `@page` 처리)은 노트 기획 산출물과 함께 다시 검토한다.

### 6.7 표·그래프 (원래 질문 6)
1. **탐지**: 비전 `SlideDoc.figures`(bbox, 종류, 제목, 표 셀, 차트 요약). 같은 호출에 들어가므로 추가 비용이 없다.
2. **크롭**: 메모리의 키프레임 원해상도에서 잘라 WebP(q80, ≤1200px, `OffscreenCanvas.convertToBlob`)로 만들고 패키지에 암호화해 저장한다. **슬라이드 전체는 저장하지 않는다.**
3. **중복 제거**: dHash 64bit, 해밍 거리 ≤ 6이면 같은 도표로 보고 가장 완성된 버전 하나만 남긴다.
4. **선택**: 종류가 장식·사진이 아니고, T4 핵심 확률, 체류시간, 지시어 언급을 본다. 섹션당 상한은 Note 스펙을 따른다.
5. **배치**: 그 슬라이드의 시간이 속한 섹션 안, 해당 내용 바로 뒤. 정확한 블록 위치는 Note 스펙을 따른다.
6. **표현**: 표는 셀 신뢰도가 충분하면 **HTML 표로 재조판**하고, 아니면 크롭을 넣는다. 그래프·다이어그램은 크롭을 넣는다.
7. **설명 입력**: 차트 요약(축·계열·추세), 정렬된 발화, 표 셀을 제공한다. 설명 항목 구성은 노트 기획에서 확정한다. 초안 제안은 캡션, 무엇을 보여주나, 읽는 법, 강조점, 시험 포인트다.
8. **Free**: 도표 탐지가 없으므로 부록에 그 사실을 적는다.

## 7. 병렬화와 스케줄링 (수정 2)

원칙: **분·토큰 단위 과금이라 잘게 나눠도 원가는 거의 같고, 소요 시간은 가장 느린 조각 하나에 수렴한다.** 늘어나는 것은 반복되는 프롬프트 접두부뿐이고, 캐싱으로 상쇄된다.

| 단계 | 단위 | 병렬도(기본, 서버에서 원격 조정) | 경계 처리 |
|---|---|---|---|
| 미디어 수신 | 세그먼트 | 수신 4, 디코드 1~2 | 백프레셔, 즉시 해제, 정준 시각 |
| STT | ≤5분 청크 | 4 | 무음 경계, 1~3초 겹침, 단어 타임스탬프로 중복 제거 |
| 전환 판정 | 키프레임 | 디코드는 병렬, **비교는 순차** | 경계 누락 없음 |
| 비전 | 안정 슬라이드 | 8 | 슬라이드끼리 독립 |
| 판정 | 항목 묶음 | 2 | 독립 |
| 계획 | 전체 IR | 1 | 전역 시야가 필요 |
| 작성 | 섹션 | ≤ 8 | 섹션 경계는 Planner가 정한다 |

- **스케줄러**: 단계 사이를 **상한 있는 비동기 큐**로 잇는다. 큐가 차면 생산자가 기다린다(백프레셔). 그래서 비전 대기열이 쌓이면 수신이 멈춘다.
- **스트리밍 실행**: 수신과 B~D를 겹쳐 돌린다.
  - 유료: 미디어 2~10분이 병목이고, 이후 계획 약 20초, 작성 약 30초 → **합계 약 4~12분**(추정).
  - Free: 재생 중에 로컬 인식과 C 단계까지 끝내 두므로, 종료 후 E~H만 남는다. 로컬 엔진은 늘리지 않는다(M1 8GB, OCR 1과 Whisper 1).
- **Rate limit**:
  - 운영 키를 모든 사용자가 공유하므로 서버에 공급자별 세마포어와 사용자별 토큰 버킷을 둔다. 넘으면 대기열 또는 `429 + Retry-After`.
  - 공급자의 rate limit 티어(예: Groq의 오디오 초·RPM)를 Phase 0에서 확인하고, 필요하면 상향을 신청한다(D11).
- **배치 API(50% 할인, 최대 24시간 지연)**: 대화형 제품에 맞지 않아 제외한다.

## 8. 신뢰성

**작업 상태 기계**
- 진행: `created → acquiring_source → ingesting(인식 병행) → refining → judging → planning → writing → validating → rendering → done`
- 예외: `paused(auth|quota|user|network)`, `failed(code)`, `cancelled`
- 상태가 바뀔 때마다 패키지에 암호화 체크포인트를 남긴다. offscreen이나 브라우저가 종료되면 재시작할 때 재개를 제안한다.

**단계 결과 캐시와 멱등성**
- 각 단계 결과를 `sha256(stage, inputDigest, model, promptVersion, schemaVersion)` 키로 패키지에 저장한다.
- 다시 생성할 때 바뀐 단계 이후만 실행한다. 템플릿만 바뀌면 E~H만 돌고, LLM 비용만 든다.
- 모든 서버 요청에는 `requestId`가 붙는다. 서버는 같은 `requestId`의 두 번째 요청을 409로 막으므로(예약·다이제스트 중복 방지) **같은 요청이 두 번 과금되지 않는다.** 서버는 결과를 저장하지 않아 같은 id로 다시 보내도 결과를 돌려받을 수 없다.

**재시도 책임 분리**
- 서버: 형식 오류나 잘린 응답만 같은 모델·공급자로 1회 재시도한다(기존 방식).
- 클라이언트: 네트워크 오류, 429, 5xx는 지수 백오프(1초×2ⁿ, 지터 ±20%, 최대 3회)로 재시도하고 `Retry-After`를 따른다. 시도마다 **새 `requestId`**(`base-r1`, `base-r2` …)를 쓴다(구현 중 변경: 같은 id는 위의 409에 막힌다). 재시도 대상은 환불되는 오류(공급자 대기 초과·요청 한도)와 응답 전 네트워크 오류다. `AbortError`(시간 초과 포함)는 공급자가 처리했을 수 있어 자동 재시도하지 않는다(`lib/pipeline.js` `withRetry`).
- 공급자별 회로 차단기: 연속 5회 실패하면 60초 동안 즉시 실패시키고 명확한 코드를 낸다.
- 취소: `AbortController`를 전 단계에 전파한다. 서버는 상류 요청을 중단하고 예약을 해제한다.

**장애 모드 (FMEA)**
| 장애 | 감지 | 동작 |
|---|---|---|
| 인증 만료, 서명 URL 만료 | 401·403 | 일시정지, 탭을 다시 열도록 요청(`SRC_AUTH_EXPIRED`) |
| 보호조치 | EME, EXT-X-KEY, ContentProtection | 백그라운드 중단, 실시간 모드 제안(`SRC_PROTECTED`) |
| 세그먼트 디코드 실패 | 디코더 오류 | 그 구간을 건너뛰고 공백 구간으로 고지 |
| STT·비전 429·5xx | 상태 코드 | 백오프 후에도 실패하면 일시정지하고 묻는다. **로컬 엔진으로 자동 전환하지 않는다** |
| 비전 스키마 오류 | 검증 | 1회 재시도, 실패하면 그 슬라이드를 미인식으로 고지 |
| LLM 출력 잘림 | `finish_reason=length` | 섹션을 나눠 다시 요청 |
| 검증 실패 블록 | 검증기 | 1회 재생성, 실패하면 제외하고 부록에 고지 |
| 메모리 예산 초과 | 바이트 회계 | 수신 일시정지, 지속되면 `MEM_BUDGET_EXCEEDED` |
| 월 한도 초과 | 서버 예약 | **지출 전에** 거부하고 남은 한도를 안내 |

**오류 코드 체계**: `<영역>_<원인>` 형식(`SRC_*`, `NET_*`, `STT_*`, `VIS_*`, `JDG_*`, `LLM_*`, `VAL_*`, `QUOTA_*`, `CONSENT_*`, `MEM_*`). 각 코드에 `retryable` 여부와 사용자 메시지를 매핑하고, UI·로그·`usage_events`에서 같은 코드를 쓴다.

**암호 설계**
- 레코드 암호화: AES-256-GCM, 레코드마다 96bit 무작위 IV. AAD = `{store, recordId, schemaVersion}`으로 슬롯을 묶어 레코드 바꿔치기를 막는다.
- 기기 키는 non-extractable `CryptoKey`로 IndexedDB에 둔다.
  - 한계: 같은 프로필에서 확장 코드를 실행할 수 있는 공격자는 막지 못한다. 문서에 명시한다.
- **전체 삭제 = 키 폐기(crypto-shredding)**. 즉시 복호화가 불가능해진다.
- 진단 파일: 임시 ECDH P-256 → 운영자 정적 공개키(`kid`로 회전 지원) → HKDF-SHA256 → AES-256-GCM. 복호화 도구는 `tools/decrypt-diagnostic.mjs`이고, 개인키는 오프라인 보관한다.
- 보존 내구성: `unlimitedStorage` 권한으로 패키지 축출을 막는다. 강의당 약 4MB(크롭 ≤30장 기준 추정)다.

**동의 체계** (모두 버전이 있고, 버전이 바뀌면 다시 받는다)
1. 외부 요약 처리: 정제 텍스트를 서버·LLM으로 보낸다. 전 등급(기존).
2. 클라우드 인식: 프레임·오디오를 보낸다. 유료(기존 비전 동의를 오디오까지 확장).
3. 사용 범위 2항목(D9): 백그라운드에 필요.

**법·정책 준수**
- **개인정보보호법**: 처리위탁과 **국외이전 고지**(Groq, OpenRouter와 하위 공급자, TypeSafe 등 미국 소재). 계정을 삭제하면 프로필·보관함·피드백을 지우고, `usage_events`는 user_id를 비식별화한 뒤 집계만 남긴다. Supabase 리전은 서울을 권장한다(국외이전 범위 축소).

- **불변식 갱신**: AGENTS.md를 고친다(§20). 이 계획을 승인하는 것을 "명시 지시"로 간주한다.
- **저장소 위생**: 커밋된 강의 파생물(`electric_circuits_*`, `lecture_summaries/`, `lecture_timeline_original.md`)을 삭제한다. 골든셋은 저장소 밖에 둔다.

## 11. 서버 설계

| 라우트 | 입력 | 한도 | 출력 | 등급 |
|---|---|---|---|---|
| `GET /v1/me` | — | — | 등급, **기능 플래그**, 한도, 병렬도·처리량 설정, `minClientVersion`, 프롬프트·스키마 버전 | 전체 |
| `POST /v1/stt` | m4a + `{t0, lang, prompt, requestId}` | ≤8MB, ≤5분 | `Transcript` 조각 | 유료 |
| `POST /v1/vision` | JPEG + `{slideId, mode: full\|reread, region?, requestId}` | ≤1.5MB | `SlideDoc` | 유료 |
| `POST /v1/judge` | `{task, items[≤200]}` | ≤64KB | `JudgeResult[]` | 유료 |
| `POST /v1/plan` | IR + Note 스펙 버전 | ≤256KB | `Plan` | 전체(Free는 월 한도) |
| `POST /v1/write` | 섹션 유닛 + Plan 조각 | ≤64KB | 블록 JSON | 전체(Free는 월 한도) |
| 보관함 라우트(기존) | 암호문 envelope | 기존 16MiB | — | 전체(용량은 정책) |

- **인증**:
  - Supabase Auth(구글 로그인, `chrome.identity.launchWebAuthFlow`)로 바꾼다.
  - 서버는 JWT를 JWKS나 프로젝트 시크릿으로 검증한다. 기존 정적 토큰(`appSessionToken`)을 대체한다.
- **한도와 예약**:
  - 기존 `withReservation`의 의미(사전 예약 → 정산 → 미보고 비용은 예약 유지)를 Postgres로 옮긴다.
  - 잔액 갱신은 단일 SQL 조건부 `update … where used + $1 <= cap returning`으로 **원자적으로** 한다.
  - 원장 `usage_events`(추가 전용)와 잔액 `monthly_usage`를 분리한다.
- **동시성**: 공급자별 세마포어(인스턴스 메모리)와 사용자별 토큰 버킷.
  - 천장: 단일 인스턴스 기준이다. 다중 인스턴스로 가면 Postgres advisory lock이나 공유 카운터로 옮긴다.
- **오류 봉투**: `{error:{code, message, retryable, retryAfterMs}}`. 코드 체계는 §8과 같다.
- **버전 관리**: `/v1`은 추가만 하는 변경으로 유지한다. 응답에 `promptVersion`·`schemaVersion`을 싣는다. `X-Client-Version`이 `minClientVersion`보다 낮으면 `426`을 돌려준다.
- **프롬프트·스키마**는 `server/prompts.js`에서 버전으로 관리한다. 웹스토어 심사 없이 개선할 수 있다.
- **공급자 설정**: OpenRouter는 기존대로(`zdr:true`, `data_collection:"deny"`, `allow_fallbacks:false`, 공급자 고정). Groq는 조직 설정에서 ZDR을 켠다. Jev는 채택 시 기업 무보존 계약. 나머지는 레지스트리에 보존 조건을 기록한다.
- **호스팅 요건**:
  - 요청 본문 ≥ 8MB, 요청 시간 ≥ 150초인 **컨테이너 런타임**(Cloud Run 서울, Fly.io 등). Vercel Functions는 본문 4.5MB 한도라 STT 경로에 맞지 않는다.
  - CORS는 확장 출처만 허용한다(기존 `origin` 검사). HTTPS와 HSTS를 쓴다.
  - 본문은 로깅하지 않는다. DB 상태를 Supabase로 옮기면 서버가 무상태가 된다.

- 배치 단위로 AES-GCM 암호화해 IndexedDB `logs`에 쓴다. 14일 또는 20MB에서 오래된 것부터 지우고, 설정에서 즉시 삭제할 수 있다.
- **발화·슬라이드 텍스트는 넣지 않는다.** 내용 수준의 디버깅은 패키지로 한다.
- **진단 파일 보내기**: 사용자가 실행한다. 복호화 → 운영자 공개키로 다시 암호화 → 다운로드 → 지원 메일. 운영팀은 `tools/decrypt-diagnostic.mjs`로 연다.

**원가 관리**
- 작업별 사전 예약(기존), 사용자별 월 한도, 전역 일일 상한(기존 `GLOBAL_COST_CENTS`), 공급자 콘솔의 지출 상한.
- 매월 `usage_events` 합계를 공급자 청구서와 대조한다(±5%).
- SLI(§4)는 어드민의 작업 탭과 서버 집계에서 계산한다.

## 14. 테스트 (D12)

### 14.1 전략
- **피라미드**:
  - 단위(순수 함수: boilerplate, formulas, preprocess, 청크 중복 제거, HLS·DASH 파서, 정준 시각)
  - 계약(라우트 JSON Schema, 기록된 공급자 응답 픽스처)
  - 통합(로컬 서버 + 모의 공급자 + 확장 스모크)
  - E2E 벤치(골든셋, 실제 공급자, 수동 또는 야간)
- **CI**(GitHub Actions, PR마다): `node --test lib/*.test.js server/*.test.js`와 `node tools/package-cws.mjs --dry-run`(불변식 감사). **유료 API 호출 0.**
- **픽스처**:
  - 저장소에는 **합성 픽스처만** 둔다. 기존 `tools/sample-*.txt` 패턴을 따르고, 합성 슬라이드 영상으로 만든 HLS(평문, AES-128, DISCONTINUITY, I-frame 재생목록)를 쓴다. 생성 스크립트도 함께 둔다.
  - 실제 강의 골든셋 3개(재무 4522310, 회로, 말 위주)는 **저장소 밖**(gitignore된 암호화 경로)에 두고, 수치만 `docs/bench-v2.md`에 커밋한다.
- **지표 정의**:
  - 한국어 **CER**(공백·문장부호 제거 후 음절 단위). 한국어는 띄어쓰기 변동이 커서 WER보다 CER이 맞다.
  - 용어 재현율(슬라이드 용어 목록 대비).
  - 수식 정규화 일치율, 표 셀 F1, bbox IoU≥0.5 일치율.
  - 판정 정확도와 ECE.
  - 워터마크 유출 건수, 원가/강의시간, p50/p90.
- **장애 주입**: 모의 공급자(429, 500, 지연, 잘린 JSON)와 HLS 픽스처 서버(403 만료, 404 세그먼트, 연결 끊김).
- **무작위 테스트**: 시드를 고정한 PRNG로 겹침 중복 제거, 문서 빈도 필터, 시간축 변환을 검사한다. 의존성을 추가하지 않는다.
- **메모리 계측**: CDP(`Performance.getMetrics`, 프로세스 RSS)로 스모크 중 피크를 잰다. Phase마다 M1 8GB 실기에서 1회 측정한다.

## 16. 실행 방식·협업·문서 (D15)

**역할**
- **오케스트레이터(Claude)**: 작업을 파일 1~2개 단위로 쪼개고 브리프를 쓴다. 계약 고정, diff 검토, 테스트·감사 실행, 커밋(Conventional Commits)을 맡는다.
- **`/devin-delegation`**(`swe-2-high`, 단순 작업은 `swe-2-medium`, `accept-edits`): 작업 1건 = 구현과 단위 테스트 초안.
  - 300초에 강제 종료 유예 5초. 셸과 테스트는 호스트가 실행한다.
  - **작업 폴더 하나에 편집 세션 하나.** 병렬로 돌릴 때는 `.worktrees/<task>`(이미 gitignore됨)를 작업마다 둔다.
  - 세션을 시작할 때 `devin auth status`와 연결 확인을 한다. 브리프 마지막 줄에 `MODEL:` 자기보고를 넣는다.
- **`/agy-delegation`**(`gemini-3.8-flash-high`, 읽기 전용, `--disable-slash-commands`, `--add-dir`):
  - Devin diff의 세컨오피니언 리뷰
  - 불변식 감사(원본 미디어 미저장, 로그 무내용, 동의 게이트)
  - 벤치 결과와 대용량 로그 요약
  - vendor API(mux.js, mp4box.js, WebCodecs) 사용법 정리
  - 파일 쓰기와 가격 같은 사실값 수집은 맡기지 않는다(CLAUDE.md). `MODEL:` 자기보고로 강등 여부를 확인한다.

**작업 1건의 흐름**: 브리프(목표, 절대경로, 수정 허용 파일, 계약, 금지 사항, 완료 조건) → Devin 구현·테스트 → 호스트 `node --test`와 패키저 `--dry-run` → agy 리뷰 → Claude 최종 검토 → 커밋.

- **단계적 출시**: 내부 계정 → 베타(기존 초대 코드 `codes` 사용자) → 전체. 다음 단계로 가는 기준은 SLO를 1주간 충족하는 것이다.
- **웹스토어 제출 체크리스트**:
  - 단일 목적 서술
  - 권한별 사유: 추가는 `webRequest`, `declarativeNetRequestWithHostAccess`, `identity`, `power`, `unlimitedStorage`. 제거는 BYOK 경로의 `https://openrouter.ai/*`.
  - Privacy practices, 개인정보처리방침 URL, 범용 도구 문구
  - 설치 경고가 바뀌는 권한은 `optional_permissions`로 옮길 수 있는지 패키징 단계에서 확인한다.
- **롤백**: 서버 플래그 끄기(즉시) → 이전 컨테이너 리비전 → 확장 이전 버전 재게시.
- **런북**:
  - 공급자 장애: 해당 기능 플래그를 끄고 상태를 고지한다.
  - 키 회전: 시크릿을 교체하고 재배포한다.
  - 원가 급증: 전역 상한을 내린다.
  - 진단 파일 처리: 복호화한 뒤 삭제한다.
  - 사이트 호환성 이슈: 사이트별로 백그라운드를 끈다.
