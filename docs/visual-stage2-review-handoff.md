# 2단계 검토 결과와 3단계 인계 — 2026-10-04

클라우드 세션(Opus)이 `b/visual-suppression`의 `bd9ad14`를 검토한 결과다. 코드 변경은 없고, 재현 스크립트 `tools/visual-flow-check.cjs`만 추가했다(`node tools/visual-flow-check.cjs`). 검토 시점의 `node --test lib/*.test.js`: 117/117 통과.

## 검토 질문

2단계 테스트에서는 근거 텍스트가 그림을 설명하는 글이었다. 그런데 실제로는 그림 속 글자와 그림 자체가 입력되고, 그 글자가 다시 그린 그림에 그대로 들어간다. 이 경우 2단계 테스트와 다르게 흘러가지 않는가?

## 결론

- 그림 오생성 차단은 실제 경로에서도 유지된다. 다만 모든 visuals를 내용과 무관하게 보류하기 때문이다(`lib/summary.js` `heldVisuals++`). `suppression-check`의 0 mismatch는 판별력이 아니라 전부 보류한 결과다. 정상 그림을 살리는 능력은 측정된 적이 없다.
- 수식과 본문은 테스트와 다르게 흘러간다. 아래 1, 4번은 3단계 전에 고칠 2단계 회귀다.

## 발견 사항

1. **근거 모양이 다르다.** 제품에서는 PP-OCR 줄이 `layoutText`를 거쳐 `EvidenceStore.add`로 들어가고, 이때 `\s+`가 공백 하나로 합쳐진다(`lib/evidence.js:3,7`). 그래서 화면 한 장이 근거 한 줄이 된다. 테스트는 이 단계를 건너뛰고 `x=2`, `x=\n2` 같은 단독 근거를 바로 넣었다.
   - 실제 코퍼스를 제품 경로로 돌리면 수식 복원은 0/6이다. 허용 대조군은 화면에 수식 한 줄만 있을 때만 생긴다.
   - 반대로 여러 줄 수식 보류 보장은 실제로 깨진다. `y =` 다음 줄에 `mx + b`가 오면 `y = mx + b`로 합쳐져 허용된다. `visual-suppression-check.mjs`의 `multiline-equation` 사례와 `summary.test.js`의 "raw OCR before whitespace normalization" 테스트는 정규화를 건너뛰어서만 통과한다.
2. **그림 속 글자를 그대로 옮기면 OCR 오독이 "근거 있음"으로 통과한다.** 기준이 "출력 = OCR 문자열"이기 때문이다.
   - 재현 결과, 세로 분수 x=½를 `x = 12`로 읽거나 마이너스가 빠진 `x = 2`를 그대로 옮기면 허용된다.
   - 코퍼스에서 실제로 나온 오독은 다음과 같다: `ax2`(ax²), `√62-4ac`(b²), `Y1`/`Y2`(y₁/y₂), `*1`(x₁), `γ`(y), `중`(세로 축 라벨, 신뢰도 0.09).
   - 이제 본문에서 수식 표기를 금지하므로 이런 오독이 본문에 그대로 실릴 수 있다. 본문에는 수치 검사가 없다.
   - 4단계에서 라벨 텍스트 대조는 항상 통과한다. 연결·부호·첨자·축 대응은 원본 이미지와 직접 비교해야만 검증된다.
3. **비전(클라우드) 엔진에서는 그림 설명문이 실제로 근거가 된다.** `server/index.js:14` `VISION_PROMPT`가 수식은 `$...$`, 표는 마크다운 표, 그래프는 한두 문장 설명으로 적게 한다. 이 경로는 2단계 테스트에 한 건도 없다.
   - 수식은 전부 보류되므로 안전하다.
   - 설명문이 틀려도 본문에 그대로 들어간다.
   - 근거의 `$..$`를 인용한 항목은 탈락한다. 핵심 결론이 전부 탈락하면 청크 요약 자체가 실패한다.
4. **`richStructure`가 정상 문장을 오탐한다(회귀).**
   - 제목이 `Graph theory 3강`이면 요약 전체가 실패한다(`lib/summary.js:155`의 throw).
   - `|x| < 1 이면 수렴`, `Pie chart는 …`, `Graph theory의 정의`, `가격은 $5에서 $10로`가 들어간 항목은 탈락한다. 결론이 그것 하나뿐이면 요약이 실패한다.
   - 2단계 이전 프롬프트는 본문에 `$...$`를 강제했다. 그래서 기존 보관 노트를 열면(`offscreen.js:30`) 수식이 있는 항목이 모두 빠지고, 결론이 전부 수식이면 노트가 열리지 않는다. 저장소의 `lecture_summaries/*`에도 수식 줄이 수십에서 수백 개 있다.
