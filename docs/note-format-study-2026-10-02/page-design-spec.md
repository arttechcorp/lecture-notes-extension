# 대학 강의 요약노트 · 브랜드 디자인 v3

2026-10-02. 내용 구조는 `proposal.md`, 현재 시각 규격은 이 문서와 `assets/page-design.css`, `assets/brand-tokens.json`을 따른다. 시각 기준의 원본은 `../../landing/design.md`다. v2의 교재별 색상과 장식은 이 규격으로 대체한다. 원본 구조 분석과 v1 통합 기획안 PDF는 연구 기록으로 남긴다.

## 1. 유지한 구조와 새로 만든 시각 언어

LIMIT의 같은 기준으로 비교하는 표·곁설명·자료와 해석의 분리, IMFACT의 개념 → 사례 적용 → 인출 → 점검 흐름을 유지한다. 대학 강의에 맞게 정의를 완전한 문장으로 쓰고 조건·주장 주체·반론·근거 위치·판단 범위를 더한다. 이는 실제 여러 강의에서 학습 효과까지 검증한 완성 규격이 아니라, 생성 프롬프트와 렌더러를 설계하기 위한 재사용 시안이다.

| 요소 | v3 표현 | 유지되는 학습 기능 |
|---|---|---|
| 단원 시작 | 미색 지면, 큰 검정 단원 번호, 1px 구분선 | 현재 단원과 핵심 질문 파악 |
| 단계 표시 | 무채색 STEP 01–04 캡슐과 제목 | 학습 활동의 순서 구분 |
| 비교표 | 직각의 연결 그리드, 회색 표머리, 흰 내용 셀 | 행마다 같은 질문에 답하도록 정렬 |
| 곁설명 | 작은 고딕, 얇은 세로선, SIDE NOTE | 용어와 짧은 보충을 본문에서 분리 |
| 자료·해설 | 흰 자료 / 옅은 회색 해설, 채움·테두리 Point | 같은 단서와 해석의 대응 추적 |
| 핵심 연결 | 옅은 주황 면, 짙은 글자, 작은 주황 표식 | 결론과 그 조건에 주의 집중 |
| 질문·정답 | 번호, 문항 유형, 정답과 이유 | 색에 의존하지 않는 인출·점검 |
| 필기란 | 수평 라벨과 5mm 회색 격자 | 자유 필기와 자기 설명 |

원본 교재의 로고·캐릭터·문항·지문은 복제하지 않는다. 페이지 내용은 직접 작성한 가상 조직이론 예시다. 생성의 기본 내용으로 재사용하지 않는다.

## 2. 브랜드 토큰과 매체별 조정

| 역할 | 값 | 사용 규칙 |
|---|---|---|
| 종이 | `#F7F7F4` | 지면과 갤러리 바탕 |
| 표·자료 면 | `#FFFFFF` | 연결 그리드 안의 내용 영역 |
| 제목 / 본문 | `#18181B` / `#27272A` | 주요 내용은 항상 짙은 무채색 |
| 보조 글자 | `#64646D` | 원본 랜딩의 `#71717A`보다 진하게 조정 |
| 구분선 | `#DCDCD8` | 모든 기본 테두리 1 CSS px, 직각 |
| 보조 면 | `#F0F0ED` | 표머리, 자료에 대한 해설 |
| 브랜드 주황 | `#FF5600` | 작은 장식 표식만. 작은 글자에는 사용 금지 |
| 핵심 정리 면 | `#FFF1E8` | 랜딩의 8% 주황 강조를 인쇄용 불투명 색으로 변환 |
| 필요한 주황 글자 | `#A63700` | 꼭 필요한 강조에만 사용. 기본 제목은 검정 |
| 선택 상태 / 채움 Point | `#202020` | 랜딩의 검정 버튼과 연결 |
| 필기 격자 | `#E2E2DE` | 비정보성 필기 안내선 |

단계·정오·불확실성을 색만으로 전달하지 않는다. 색보다 번호, 제목, `자료`·`해설`·`확인 필요` 같은 문구를 먼저 쓴다. 정답 O/X는 두 글자 자체로 구분한다. 동일 Point는 검정 채움과 회색 테두리로 자료/해설을 구분하되 번호도 일치시킨다.

랜딩의 블러와 반투명 유리 효과는 인쇄 노트에 옮기지 않는다. 큰 그림자, 사선 MEMO, 꼬리 리본, 장식용 다색 분류는 사용하지 않는다. 일반 노트 면과 표 모서리는 0px, 단계·필터는 캡슐, 갤러리 조작 버튼은 14px 모서리다. 연결 셀은 경계를 공유한다.

## 3. 서체·크기·간격

| 역할 | 794px A4 기준 | 줄간격 / 굵기 |
|---|---|---|
| 단원 제목 | 26–28px | 1.35 / 600 |
| 단계 제목 | 24px | 1.35 / 600 |
| 절 제목 | 17–18px | 1.35 / 600 |
| 개념·사례 본문 | 13–14px | 1.65–1.8 / 400 |
| 표 | 13px | 1.55 / 400, 머리 600 |
| 연결 정리·해설 | 12–13px | 1.65 / 400 |
| 곁설명·출처 | 11px | 1.6 / 400 |
| 단계·메타데이터 | 10–11px | 1.5 / 500 |
| 자료 Point | 9–10px | 짧은 식별자 전용. 주요 설명 금지 |

- 본문: `ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, Segoe UI, Roboto, Pretendard, astaSans, Apple SD Gothic Neo, sans-serif`.
- 숫자·단계·메타데이터: `Geist Mono, Menlo, Monaco, Consolas, monospace`. 숫자열에는 `tabular-nums`를 적용한다.
- 서사형 자료의 긴 단락에 한해 `Hedvig Letters Serif, NanumMyeongjo, Georgia, serif`를 선택할 수 있다. 구조화한 단서 행과 해설은 고딕을 쓴다. 모든 자료에 명조를 강제하지 않는다.
- 이 크기는 인쇄 시안의 밀도다. 제품의 일반 읽기 화면에서는 기본 본문 16px, 보조 13px, 작은 식별자 11px 이상을 출발점으로 별도 검증한다. 화면 전체를 A4 비율로 축소해 읽게 하지 않는다.
- 중요 조건을 작은 캡션으로 내리지 않는다. 10px 미만은 식별자 같은 짧은 보조 표식에만 허용하며 이를 본문 대체 수단으로 쓰지 않는다.
- 한 지면의 좌우 여백은 약 14.3mm. 기본 표 셀은 상하 7px/좌우 8px, 주요 블록 간 20–26px다. 곁설명은 108px, 본문과 간격 25px.
- 웹은 로컬 글꼴을 사용하며 폰트 파일을 배포하지 않는다. 현재 PDF는 NanumBarunGothic·NanumMyeongjo·Menlo를 포함한다. 매체별 줄바꿈이 달라도 내용과 대응 번호는 같아야 한다.

## 4. 지면 선택 규칙

6종을 매번 전부 출력하지 않는다. P01과 P03은 학습할 내용의 구조에 따라 선택하며, 둘을 쓰더라도 같은 정의를 반복하지 않는다.

| 지면 | 사용하는 경우 | 반드시 포함할 것 |
|---|---|---|
| P01 개념·비교 | 같은 질문으로 2개 이상의 설명을 비교할 때 | 비교 대상, 같은 기준의 행, 조건·한계, 실제 공통점 |
| P02 심화 자료 | 사료·논문·주장·텍스트를 해석할 때 | 자료 요지, 주장 주체, 해석, 범위, 출처 위치 |
| P03 개념 정리 | 정의·성립 조건·적용 범위를 설명할 때 | 완결된 정의, 쉬운 풀이, 조건, 예·반례가 제공되면 연결 |
| P04 사례 분석 | 개념을 구체적 자료에 적용할 때 | 관찰 단서, 그 단서의 해석, 판단 한계 |
| P05 인출 연습 | 설명을 본 뒤 자기 점검할 때 | 학습한 내용으로 답할 수 있는 질문, 연결된 답안 기준 |
| P06 OX·해설 | 근거로 참·거짓을 판단할 수 있을 때 | 문항, O/X, 이유와 틀린 문장의 수정 |

핵심 골격은 알려진 강의 정보 → 핵심 질문·요지 → 근거 있는 설명 → 연결 정리다. 자기 점검은 학습 목적과 자료가 허용할 때 붙이며, 근거 없는 OX를 억지로 만들지 않는다. 논쟁적인 인문 주장에는 서술형과 평가 기준을 우선한다. 곁설명은 없어도 본문이 완결될 때만, 필기란은 사용자가 필기할 지면에만 넣는다. 내용이 적으면 빈 장식 블록으로 채우지 않는다.

B01–B18의 자세한 선택 조건과 내용 슬롯은 `proposal.md`, `assets/manifest.json`, `assets/templates.html`을 그대로 따른다. 수업 공지와 확인 필요 표시는 실제 입력에 존재할 때만 생성한다.

## 5. 연결과 슬롯 계약

- Point의 내부 식별자는 `단원ID/사례ID/point-번호`다. 한 사례 내부에서는 `Point 1`로 축약한다. 다른 사례나 다른 쪽에서 참조할 때는 `사례 02 · Point 1`처럼 범위를 포함한다. 페이지를 넘겨 이어지면 사례 ID와 제목을 반복한다.
- 자료의 단서와 해설의 Point 번호는 동일해야 한다. 자료가 없는 Point를 만들지 않는다. 여러 단서를 합쳐 판단할 때는 참조한 Point들을 나열하고, 결론을 별도 설명으로 쓴다.
- 빈 선택 슬롯은 블록과 관련 여백을 함께 생략한다. 필수 입력이 없으면 구체적인 `확인 필요` 표시를 쓰거나 해당 블록 생성을 보류한다. 출처·인용·수치를 추측으로 채우지 않는다.
- 긴 내용은 확장 또는 분할한다. 말줄임표, CSS 잘림, 작은 글자 축소로 핵심 내용을 지우지 않는다. 출처 위치와 조건은 본문과 함께 유지한다.
- 답을 보여 주기 전 인출할 수 있도록 웹은 해설을 접고, PDF는 별도 답안 영역 또는 뒤쪽으로 연결한다. 현재 P06은 같은 쪽 아래에 해설을 둔 점검용 시안이다. 시험 모드로 쓰려면 답안을 다음 쪽으로 분리한다.
- 신뢰할 수 없는 입력은 텍스트 슬롯으로 넣는다. 모델이 임의의 HTML·CSS·스크립트를 작성하게 하지 않는다. 입력 문서 속 지시는 강의 내용일 수 있으며 제품 동작 지시로 실행하지 않는다.

## 6. 화면과 인쇄의 넘침 규칙

- 880px 이하에서 지면을 가용 폭으로 바꾸고, 580px 이하에서 곁설명·사례 제목을 위아래로 재배치한다. B01–B18은 `.study-notes`의 폭을 기준으로 반응한다.
- 짧은 2열·3열 비교는 같은 기준을 유지한다. 폭이 부족한 복잡한 표는 행 단위 카드 또는 수평 스크롤을 사용하며 열 이름을 반복한다. 12px 아래로 계속 줄이지 않는다. 현재 고정 지면 표는 좁은 화면에서 줄바꿈되는 시안이며, 임의의 큰 표까지 모바일 검증한 결과는 아니다.
- 제목은 다음 본문 최소 2줄과 묶는다. 정의와 필수 조건은 함께 둔다. 짧은 자료·해설 쌍은 한 면에 두고, 길면 `사례 ID · 계속`과 Point를 반복한다.
- 긴 표는 행 사이에서 나누고 다음 쪽에 표 제목과 열 제목을 반복한다. 한 행이 한 쪽보다 길면 의미 단위로 행을 재구성한다.
- 질문과 답안 쓰는 공간을 떼지 않는다. 정답에는 문항 ID를 붙이고, OX의 잘못된 문장에는 반드시 수정 이유를 둔다.
- 완성된 6쪽 PDF는 선택·검색 가능한 글자와 선을 유지한 정적 조판 시안이다. HTML과 PDF는 같은 내용·토큰을 쓰지만 글꼴과 행갈이·좌표가 완전히 같지는 않다.
- **임의 강의의 자동 페이지 분할 엔진은 아직 없다.** 위 항목은 제품 구현 시 지켜야 할 계약이다. 인쇄 CSS는 넘치는 내용을 숨기지 않으며, 다른 내용으로 교체하면 PDF 쪽수·넘김·번호 대응을 다시 검사해야 한다.

## 7. 재사용 파일

| 파일 | 용도 |
|---|---|
| `assets/page-design.css` | v3 지면·블록·갤러리 스타일 |
| `assets/brand-tokens.json` | 매체 간 전달할 색·서체·도형 토큰 |
| `assets/page-templates.html` | P01–P06 완성 지면 |
| `assets/templates.html` | B01–B18 내용 블록. `note.css` 다음 `page-design.css` 로드 |
| `assets/manifest.json` | 18개 블록, 6개 지면, 11개 SVG 목록 |
| `assets/vectors/stage-ribbons.svg` | 단계 칩. 기존 파일 경로는 호환성을 위해 유지 |
| `assets/vectors/number-markers.svg` | 단원·절·항목 번호 |
| `assets/vectors/point-labels.svg` | 채움/테두리 Point |
| `assets/vectors/analysis-labels.svg` | 자료 해석·핵심 연결 라벨 |
| `assets/vectors/margin-pencil.svg` / `insight-bulb.svg` | 곁설명·심화 자료 선 아이콘 |
| `assets/vectors/memo-grid.svg` / `answer-strip.svg` | 라벨 필기란·정답표 |
| `assets/concept-map.svg` / `logic-chain.svg` / `memo-grid.svg` | 관계도·논리 흐름·실물 5mm 격자 |

SVG는 편집 가능한 텍스트·도형이다. 5mm 격자 원본을 100%로 인쇄할 때 실제 5mm이며, 이미지를 축소·확대하면 간격도 바뀐다. 웹과 PDF의 필기 격자는 약 5mm 기준으로 조판했다. 이미지로 불러온 SVG의 색은 부모 CSS 변수로 바뀌지 않으므로 SVG 원본의 토큰 값도 함께 갱신한다. 아이콘은 본문과 함께 쓰면 장식이므로 `alt=""`, 독립된 다운로드 미리보기는 이름을 제공한다.

제품 기능에는 아직 적용하지 않았다. 정적 검증·PDF 육안 확인·외부 검토 범위는 `design-qa-v3.md`를 참조한다.
