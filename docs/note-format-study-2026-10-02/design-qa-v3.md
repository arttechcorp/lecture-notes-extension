# 브랜드 디자인 v3 검증 기록

- 6개 페이지의 갤러리·연속 보기·템플릿 간 텍스트 일치 확인.
- v2와 비교해 예시의 내용 유지 확인. 바뀐 텍스트는 STEP 표기와 SIDE NOTE 등 디자인 라벨.
- HTML의 중복 ID와 깨진 상대 링크 없음. SVG 전부 XML 파싱 성공. 갤러리 JS 구문 검사 통과.
- PDF 6쪽 모두 Poppler로 렌더링 후 육안 확인. 텍스트, 표, 번호, Point, 필기 격자, 바닥글에 잘림·겹침 없음.
- PDF 페이지별 글자 996 / 955 / 716 / 778 / 665 / 794개. 페이지 바깥 글자 0개. 본문 셀·문단의 텍스트 보존을 추출 결과와 대조함. PDF 추출 순서는 다단 편집에 따라 달라질 수 있음.

- `node tools/package-cws.mjs --dry-run --skip-tests`: 71개 런타임 파일 검사, 불변식 위반 0. 테스트는 별도로 위 명령으로 실행했으며 실제 CWS ZIP을 만들거나 배포하지 않음.

## 지정된 외부 검토

사용자가 호출한 `agy-delegation`과 `devin-delegation` 스킬을 사용했다. 연결 확인 뒤 300초 상한의 읽기 전용 작업으로 분리했다. 원본 교재 PDF, 실제 강의 내용, 인증 자료는 전달하지 않았다.

- Antigravity CLI 1.2.14: `--agent gemini-flash`, `gemini-3.8-flash-high`. 새 CSS와 토큰의 격리된 스냅샷을 검토. 종료 코드 0, 결과의 모델 자기보고는 Gemini 3.8 Flash. 실제 모델의 독립적인 서버 증명으로 간주하지 않음.
- Devin CLI 3000.11.3: `swe-2-medium`. 자체 완결된 디자인 브리프의 재사용·가독성 규칙을 검토. 종료 코드 0, export 메타데이터와 자기보고 모두 SWE-2 Medium. 파일 읽기나 변경을 맡기지 않음.

검토 의견은 그대로 적용하지 않고 원본 규격과 대조했다.

| 의견 | 판단과 처리 |
|---|---|
| 인쇄 스타일이 갤러리 wrapper에 의존 | `.textbook.paper-sheet` 자체로 인쇄 규칙을 적용하도록 수정 |
| 컨테이너 쿼리가 작동하지 않음 | 기존 note.css의 `.specimen`/`.note-page` 컨테이너를 못 본 지적. 갤러리 결함으로는 미확정. 독립 블록 재사용을 위해 `.study-notes`도 컨테이너로 선언 |
| 모든 자료는 명조여야 함 | 잘못 해석한 의무 규칙. 서사 단락에만 선택 사용하고 구조화한 단서와 해설은 고딕 유지 |
| 검정 버튼과 보조 회색 값이 토큰에 없음 | 랜딩의 `#202020`은 정당한 토큰이므로 JSON에 명시. 의미 있는 표식 선은 보조 글자 토큰으로 통일 |
| 높이 고정과 overflow:hidden으로 빈 쪽 방지 | 내용이 잘릴 위험이 있어 미채택. 페이지 분할 한계를 명시하고 정적 PDF를 별도 조판·확인 |
| Point 범위, 슬롯 생략, 긴 내용, 매체별 글꼴 기준 부족 | 최신 디자인 규격에 식별자·반복 제목·분할·생략·폰트 폴백 규칙 추가 |
| 핵심 정의·인출을 모든 강의에 강제 | 강의 유형마다 근거가 다르므로 미채택. 내용에 맞는 블록 선택과 질문의 근거 조건 명시 |

## 확인하지 않은 범위

- 이전 단계에서 로컬 `file://` URL의 브라우저 도구 접근이 거부되었다. 이번에는 우회 경로로 브라우저를 열지 않았다. **v3 HTML의 실제 브라우저 렌더링·모바일 동작은 재검증하지 않았다.** 소스 구조·CSS 규칙 검사와 PDF 렌더링 확인을 구분한다. 열려 있는 갤러리는 사용자가 새로고침해 볼 수 있다.
- 자동 페이지 분할, 임의 강의 데이터의 긴 표, 모든 폰트 폴백, 실제 프린터·노트앱, 스크린리더 전체 흐름, 학습 효과는 검증하지 않았다.
- 수동 조판한 PDF와 CSS 레이아웃의 줄바꿈·좌표에는 차이가 있다. 최종 생성 프롬프트와 제품 렌더러를 구현한 결과가 아니다.
