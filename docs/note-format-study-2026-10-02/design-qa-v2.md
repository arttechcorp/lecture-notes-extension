# 지면 디자인 v2 확인 기록

2026-10-02. 대상은 디자인 문서와 로컬 갤러리이며 제품 기능은 변경하지 않았다.

## 확인한 것

- 원본 지면 재검토: LIMIT PDF 2·3·6쪽, IMFACT PDF 1·2·3·5·7쪽을 확대해 표·주석·리본·Point·필기·OX 구조를 대조했다.
- 완성 지면 P01-P06, 기존 내용 블록 B01-B18, 새 SVG 8종의 파일·manifest 참조를 확인했다.
- 초기 갤러리의 1280·768·360 px에서 6종을 모두 선택하며 가로 넘침을 검사했다. 문서와 지면·기존 블록의 가로 넘침은 없었다.
- 지면 전환 시 정확히 한 지면 표시, 선택 버튼 상태, 해설 5개 모두 펼침, 사이드패널 폭 전환을 확인했다. JavaScript 페이지 오류는 없었다.
- OX 번호의 줄바꿈 원인은 번호열의 가용 너비보다 두 자리 숫자가 넓고 임의 줄바꿈이 허용된 점이었다. CSS에서 번호열에 `white-space: nowrap`, 작은 좌우 패딩을 적용했다.
- 심화 자료의 과도한 세로 간격, 인출 연습의 보조 설명 크기·필기란 높이, 인쇄에서 줄어드는 띠·꼬리말을 조정했다.
- 최종 PDF는 6쪽 A4다. 심화 자료의 꼬리말 위치와 OX 두 자리 번호를 PDF 조판에서도 바로잡았다. 글자·선·글꼴을 유지했고 각 쪽으로 이동하는 책갈피를 포함했다. 페이지 전체를 이미지로 만든 PDF가 아니다.
- 최종 PDF 6쪽을 모두 PNG로 렌더링해 확인했고, 마지막 보정의 영향을 받은 2·6쪽을 다시 확인했다.
- `node --test lib/*.test.js server/*.test.js tools/*.test.mjs`: 362개 통과, 실패 0.
- `node tools/package-cws.mjs --dry-run --skip-tests`: 통과, 보안·아키텍처 감사 위반 0. 테스트는 별도 명령으로 실행했으며 실제 확장 ZIP을 생성하거나 배포하지 않았다.

## 확인의 제한

- 열린 인앱 브라우저의 `file://` 탭 접근은 브라우저 URL 정책이 차단했다. 해당 탭을 자동 새로고침하거나 다른 경로로 우회하지 않았다. 파일은 갱신되어 있으므로 사용자가 새로고침해 확인할 수 있다.
- 위 반응형·동작 검사는 마지막 CSS 조판 보정 이전에 수행했다. 보정 뒤에는 파일·PDF 확인으로 마무리했으며, 최신 HTML을 열린 인앱 브라우저에서 다시 검증했다고 주장하지 않는다.
- 배포 PDF의 2·6쪽은 조판을 정리하며 약간 축소 배치했다. HTML의 흐름과 PDF의 최종 배치는 일부 다르다. 임의 분량의 강의를 자동으로 A4에 분할하는 제품 기능은 아니다.
- 실제 노트앱·인쇄기, 전체 스크린리더 동작, 다른 OS의 글꼴 대체, 실제 강의 생성 품질은 이번 확인 범위가 아니다. 밝은 장식색까지 포함한 전체 대비 적합성도 보장하지 않는다.
