Screen Notes 시작하기

재생 중인 영상 화면에서 학습 노트를 만듭니다. 온라인 강의, 화상회의 녹화, 웨비나 다시보기 등에 씁니다.

1. 이 도구가 하는 일과 하지 않는 일

  • 화면 이미지는 기기 안에서만 처리됩니다. 기본 설정에서 캡처된 이미지는 어떤 서버로도 전송되지 않습니다.
  • 아무것도 저장하지 않습니다. 캡처 이미지·인식된 텍스트·노트는 사이드패널 메모리에만 있고, 패널을 닫으면 사라집니다. 저장은 사용자가 .md로 직접 내려받을 때만 일어납니다.
  • 개발자 서버가 없습니다. 수집되는 데이터가 없습니다.
  • 영상을 다운로드하지 않습니다. 이 기능은 앞으로도 추가하지 않습니다.
  • DRM 보호 영상은 처리하지 않습니다. 보호된 영상이 감지되면 캡처를 시작하지 않고 중단합니다.
이용자 책임: 많은 교육기관이 수업 화면의 캡처·보관·제3자 전송을 규정으로 금지합니다. 사용 전 소속 기관의 원격수업 지침과 이용약관을 직접 확인하세요. 결과물을 타인에게 배포하지 마세요. 이 도구는 개인 학습용이며, 사용에 따른 책임은 이용자 본인에게 있습니다.

3. 노트 생성용 API 키 (선택)

인식된 텍스트만 넘겨서 노트를 만드는 단계입니다. 화면 이미지는 여기서 전송되지 않습니다. 키를 넣지 않으면 온디바이스 모델로 노트를 만듭니다(품질이 낮습니다).

4. 사용법

  1. 영상을 재생합니다.
  2. 확장 아이콘을 눌러 사이드패널을 엽니다.
  3. 영상이 열린 탭을 고르고, 영역 지정으로 슬라이드 부분만 선택합니다 — 발표자 얼굴이 들어가지 않게 하는 것을 권장합니다.
  4. 캡처를 시작하고, 끝나면 노트를 복사하거나 .md로 저장합니다.
