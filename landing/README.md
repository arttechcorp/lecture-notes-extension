# Summrizei 랜딩 페이지

정적 페이지 하나다. 빌드 단계가 없다 — `index.html` 을 그대로 서빙한다.

## 배포

Vercel 대시보드에서 이 저장소를 연결할 때 **Root Directory 를 `landing` 으로** 지정한다.
프레임워크는 "Other", 빌드 명령은 비워 둔다.

CLI 로 할 경우 이 폴더에서:

    vercel          # 미리보기 배포
    vercel --prod   # 운영 배포

## 아직 채워지지 않은 것

- 설치 버튼이 Chrome 웹 스토어 홈으로 간다. 등록이 끝나면 실제 확장 URL 로 바꾼다.
- 푸터의 방침 링크(`#privacy`, `#terms`, `#copyright`, `#refund`, `#oss`)는 앵커만 있다.
  각각 문서를 만들어 연결해야 한다.
- 결제를 시작하기 전에 전자상거래법상 사업자 정보를 푸터에 표시해야 한다.
  페이지 안에 점선 상자로 자리를 표시해 두었다.
