# Summrizei 랜딩 페이지

정적 페이지 하나다. 빌드 단계가 없다 — `index.html` 을 그대로 서빙한다.

## 배포

Vercel 대시보드에서 이 저장소를 연결할 때 **Root Directory 를 `landing` 으로** 지정한다.
프레임워크는 "Other", 빌드 명령은 비워 둔다.

CLI 로 할 경우 이 폴더에서:

    vercel          # 미리보기 배포
    vercel --prod   # 운영 배포

## 아직 채워지지 않은 것

- 설치 버튼이 Chrome 웹 스토어 홈으로 간다. 등록이 끝나면 실제 확장 URL 로 바꾼다.
- 푸터의 방침 링크(`#privacy`, `#terms`, `#refund`, `#oss`)는 앵커만 있다.
  각각 문서를 만들어 연결해야 한다.
- 저작권 방침과 외부 전송 안내는 저작권 방침 대화상자로 연결된다.
- `checkout-config.js`의 `basic`, `premium`에 결제 서비스의 실제 HTTPS 결제 링크를 넣는다.
  비어 있으면 결제 준비 중 안내를 표시한다. 카드 클릭만으로 과금하지 않고 결제 페이지로 이동한다.
- 결제 완료 후 확장 프로그램의 플랜을 활성화하는 로그인·웹훅·구독 상태 서버는 아직 없다.
- 결제 서비스는 Paddle을 사용할 예정이며, 현재 연결값은 비워 둔다.
- 결제를 시작하기 전에 전자상거래법상 사업자 정보를 푸터에 표시해야 한다.
  페이지 안에 점선 상자로 자리를 표시해 두었다.
