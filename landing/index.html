GOOD TO KNOW

시작하기 전에.

Free도 API 키가 필요한가요?

아니요. Free의 화면·음성 인식과 원문 타임라인은 기기 안에서 동작합니다. 현재 AI 요약을 사용하려면 개인 API 키가 필요하며, 키 없이 사용하는 유료 구독은 준비 중입니다.

플랜마다 결과가 얼마나 다른가요?

위의 예시 보기에서 같은 입력으로 생성한 결과를 비교할 수 있습니다. 한 번의 비교 결과가 모든 강의에서 같은 품질 차이를 보장하지는 않습니다. 요약의 분량보다 자신에게 편한 정리 방식을 기준으로 골라 주세요.

패널을 닫아도 노트가 남나요?

패널을 닫으면 수집한 텍스트와 노트가 사라집니다. 필요한 결과는 닫기 전에 복사하거나 Markdown 파일로 저장해 주세요.

강의 자료는 어떻게 처리되나요?

처리 방식과 전송 범위는 저작권 방침과 개인정보처리방침에서 확인할 수 있습니다.
