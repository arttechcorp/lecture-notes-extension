02. 현재 처리하는 정보

강의 화면
선택한 영상의 화면과 재생 시각을 읽습니다. 기본 화면 글자 인식은 기기 안에서 Tesseract로 처리합니다.
강의 음성
음성 인식을 켠 경우 Whisper가 기기 안에서 말소리를 텍스트로 바꿉니다. 현재 코드에는 원본 음성을 원격 인식 API로 업로드하는 경로가 없습니다.
AI 요약
요약을 요청하면 영상 제목, 재생 시각이 포함된 화면·음성 인식 텍스트, 사용자가 입력한 요약 조건을 선택한 AI 제공자에게 전송합니다.
설정
AI 제공자, API 키, 음성 인식·출력 설정, 동의 상태와 마지막으로 선택한 사이트의 출처(origin)를 브라우저 확장 저장소에 보관합니다.

03. 기기 내 보관과 내보내기

강의 캡처 이미지, 인식 텍스트와 생성한 노트는 패널 세션의 메모리에서 처리하며 확장 프로그램의 설정 저장소에 저장하지 않습니다. 패널이 종료되면 세션 내용은 유지되지 않습니다.

설정과 API 키는 Chrome의 로컬 확장 저장소에 저장합니다. API 키 동기화 옵션을 켜면 키를 Chrome 동기화 저장소에도 저장합니다.

사용자가 직접 복사하거나 내려받은 노트는 클립보드 또는 저장한 파일에 남습니다. 이 파일은 사용자가 별도로 관리합니다.

로컬 처리와 외부 제공자의 데이터 보관은 서로 다른 항목입니다. 원격 API 요청 이후의 처리·보관 조건은 아래 항목에 따로 기재해야 합니다.

04. 외부 서비스와 정보 전송

AI 제공자
현재 API 연결은 Google Gemini 또는 Anthropic Claude를 사용합니다. 원격 OCR 옵션을 켠 경우 캡처 이미지도 선택한 제공자에게 전송합니다.
모델 다운로드
Whisper를 준비할 때 Hugging Face에서 모델 파일을 내려받고 브라우저 캐시를 사용합니다. 다운로드는 음성 파일 업로드와 별개의 요청입니다.
수탁·이전 상세
작성 필요: 제공자별 법인명, 전송 항목, 목적, 처리 국가, 시점·방법, 보관기간, 거부 방법 및 영향
웹사이트 운영
작성 필요: 호스팅·폰트·분석 서비스, 접속 기록과 쿠키의 처리 여부 및 보관기간
결제 서비스
Paddle 연결 예정입니다. 작성 필요: 실제 결제 연결 후 전달 정보, 거래 기록과 보관 기준

강의 내용의 외부 전송에 관한 설명은 저작권 방침에서도 확인할 수 있습니다.
