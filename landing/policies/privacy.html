02. 처리하는 정보

강의 화면
사용자가 캡처 시작을 누른 탭의 화면 프레임과 재생 시각을 읽습니다. 화면 글자 인식은 기기 안에서 PP-OCRv5(WebAssembly)로 처리하며, 캡처한 이미지 자체는 외부로 전송하지 않습니다.
강의 음성
음성 인식을 켜면 해당 탭의 오디오를 기기 안에서 Whisper 모델(WebGPU 또는 WebAssembly)로 텍스트로 바꿉니다. 원본 음성을 외부 인식 서비스로 업로드하는 경로는 없습니다.
기기 내 요약
Chrome 내장 온디바이스 AI(Gemini Nano)를 사용할 수 있는 환경에서는 요약도 기기 안에서 수행하며, 이 경우 강의 내용이 외부로 나가지 않습니다.
원격 AI 요약 (선택)
사용자가 원격 요약에 동의한 경우에만, 기기에서 인식한 텍스트와 재생 시각·영상 제목·요약 조건을 요약 제공자에게 전송합니다. 화면 이미지와 원본 오디오는 어떤 경우에도 전송하지 않습니다.
설정
요약 모델, 원격 요약 동의 여부, 화면 글자 인식·음성 인식 사용 여부와 언어, 재생 속도 보정, 테마, 약관 동의 여부, 사용자가 입력한 OpenRouter API 키, 보관 서비스 주소와 앱 세션 토큰을 확장 프로그램의 로컬 저장소에 보관합니다.
사전 예약 (웹사이트)
사전 예약 신청 시 이메일 주소, 휴대전화번호, 관심 요금제를 수집합니다. 출시·혜택 안내 목적으로만 사용하며, 입력은 사용자의 선택입니다.

위치정보, 결제정보, 브라우징 기록, 키 입력은 수집하지 않습니다. 캡처는 사용자가 직접 시작한 탭에서만 동작하며, 다른 탭이나 백그라운드에서 화면·음성을 읽지 않습니다.

03. 기기 내 보관과 내보내기

캡처한 화면 이미지, 인식 텍스트, 생성한 노트는 확장 프로그램의 오프스크린 세션 메모리에서만 처리합니다. 확장 저장소·캐시·파일에 평문으로 저장하지 않으며, 세션이 끝나면 남지 않습니다.

설정과 키는 Chrome의 로컬 확장 저장소에만 저장하며, 계정 동기화 저장소는 사용하지 않습니다. 이전 버전이 동기화 저장소에 남긴 키는 확장 실행 시 삭제합니다. 저장소 접근은 확장 자신의 화면으로 제한합니다.

사용자가 직접 복사하거나 인쇄·저장한 노트는 클립보드와 사용자의 파일에 남으며, 이후 관리는 사용자에게 있습니다.

보관 기능을 사용하는 경우, 노트는 기기 안에서 사용자의 보관 암호로 암호화(AES-256-GCM, PBKDF2-SHA256 600,000회)한 뒤 암호문만 보관 서비스로 전송합니다. 서버는 암호와 복호화 키를 받지 않으므로 암호를 분실하면 복구할 수 없습니다.

04. 외부 서비스와 정보 전송

AI 요약 제공자
원격 요약은 OpenRouter(OpenRouter, Inc.)를 거쳐 사용자가 선택한 모델(Google Gemini 계열 또는 Anthropic Claude 계열)로 전달합니다. 사용자가 자신의 API 키를 입력한 경우 기기에서 직접 호출하고, 운영자 보관 서비스를 연결한 경우 서비스가 운영자 키로 호출합니다. 공급자를 고정하고 임의 대체(fallback)를 금지하며, 학습 사용 거부와 무보존(ZDR) 처리를 요청합니다.
전송 항목
전송: 인식 텍스트, 타임스탬프, 영상 제목, 사용자가 입력한 요약 조건. 미전송: 화면 이미지, 원본 오디오, 브라우징 기록, 계정 식별정보.
모델 파일 내려받기
음성 인식을 처음 준비할 때 Hugging Face에서 Whisper 모델 파일을 내려받아 브라우저 캐시에 둡니다. 이 요청에는 강의 화면·음성·텍스트가 포함되지 않습니다.
웹사이트 운영
웹사이트는 Vercel에 호스팅하며 접속 기록은 호스팅 사업자가 처리합니다. 사전 예약 정보는 Supabase에 저장합니다. 글꼴은 Google Fonts에서, 애니메이션 라이브러리는 cdnjs에서 불러오므로 접속 시 IP 주소가 해당 서비스에 전달됩니다. 분석 도구, 광고 추적기, 쿠키는 사용하지 않습니다.
결제 서비스
현재 확장 프로그램과 웹사이트에서 결제를 받지 않으며 결제·금융 정보를 수집하지 않습니다. 결제를 도입하는 시점에 전달 항목과 보관 기준을 이 방침에 반영한 뒤 시행합니다.

전송 구간은 HTTPS로 보호하지만, 요약 제공자는 추론을 수행하기 위해 전송한 텍스트를 일시적으로 평문으로 처리합니다. 원격 요약은 종단간 암호화가 아닙니다. 외부 전송 없이 사용하려면 원격 요약에 동의하지 않은 상태로 기기 내 인식 기능만 사용하면 됩니다.

강의 내용의 외부 전송에 관한 설명은 저작권 방침에서도 확인할 수 있습니다.
