01. 운영자와 서비스

Summrizei는 재생 중인 강의의 화면 글자와 말소리를 인식해 영상 시각이 담긴 텍스트와 학습 노트를 만드는 Chrome 확장 프로그램입니다.

이용 동의
확장 프로그램을 설치하고 처음 실행할 때 이 약관과 개인정보처리방침에 동의하면 이용계약이 성립합니다. 별도의 회원 가입과 계정은 필요하지 않으며, 확장 프로그램을 삭제하면 이용이 종료됩니다.
이용 연령
만 14세 이상이 이용할 수 있습니다.

02. 기능과 이용 범위

화면 글자 인식, 선택형 음성 인식, 인식 텍스트 확인, 학습 노트 생성과 결과 복사·인쇄를 제공합니다. 기능은 사용 중인 브라우저, 기기 성능, 영상 사이트와 선택한 설정에 영향을 받습니다.

캡처 접근이 제한된 영상, 보호된 콘텐츠, 읽기 어려운 화면 또는 음질이 낮은 구간에서는 결과가 누락되거나 인식이 실패할 수 있습니다.

생성한 노트에는 오독이나 잘못된 정리가 포함될 수 있습니다. 시험·과제 등 중요한 용도로 쓰기 전에 원래 강의와 대조해 확인해 주세요.

03. 요금

현재 확장 프로그램의 모든 기능을 무료로 제공하며, 유료 플랜과 결제는 시작하지 않았습니다.

원격 AI 요약은 사용자가 직접 발급한 OpenRouter API 키로 동작합니다. 이 경우 요약 호출에 따른 비용은 사용자와 해당 제공자 사이에서 발생하며 Summrizei는 관여하지 않습니다. 기기 내 요약과 기기 내 인식 기능은 추가 비용 없이 사용할 수 있습니다.

유료 플랜을 도입할 경우 금액·제공량·해지 조건을 결제·환불 안내와 이 약관에 먼저 게시한 뒤 시행합니다.

04. 콘텐츠와 데이터

사용자는 강의를 제공한 사이트와 권리자가 정한 이용 조건을 확인한 뒤 캡처·음성 인식·요약 기능을 사용해야 합니다. 노트를 생성했다는 이유만으로 원본 강의에 관한 권리가 이전되지 않습니다.

콘텐츠 처리와 공유 기준은 저작권 방침, 개인정보의 처리 흐름은 개인정보처리방침에 있습니다.

강의 내용과 노트는 세션 메모리에서만 처리하며 서버나 기기에 저장하지 않습니다. 필요한 결과는 패널을 닫기 전에 복사하거나 파일로 저장해 주세요.

05. 운영·변경·문의

이용 제한
DRM·캡처 차단의 우회 시도, 원본 강의의 복원·재배포, 타인의 권리를 침해하는 사용, 서비스의 정상 운영을 방해하는 행위는 제한합니다. 제한이 필요한 경우 사유를 안내하며, 이의는 아래 문의처로 접수할 수 있습니다.
서비스 변경
기능 변경·중단이 필요한 경우 웹사이트와 확장 프로그램 업데이트를 통해 안내합니다. 외부 제공자의 정책 변경으로 일부 기능이 제한될 수 있습니다.
책임 범위
운영자는 서비스 제공에 필요한 주의를 다합니다. 다만 인식·요약 결과의 정확성을 보증하지 않으며, 사용자가 결과를 확인 없이 활용해 발생한 결과에 대해서는 책임지지 않습니다. 운영자의 고의 또는 과실로 발생한 손해에 대한 책임은 관련 법령에 따릅니다.
약관 변경
약관을 변경하면 시행일을 갱신해 이 페이지에 게시하며, 이용자에게 불리한 변경은 시행 7일 전에 안내합니다.
