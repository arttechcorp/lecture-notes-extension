저작권 방침

강의 자료를 존중하면서 학습 노트를 활용하기 위한 안내입니다.

01. 강의와 노트의 활용

Summrizei는 개인 학습을 돕기 위해 화면 글자와 말소리를 정리하는 도구입니다. 사용하려는 강의의 캡처, 음성 인식, AI 처리와 결과 공유가 허용되는지는 강의 제공자와 사이트의 이용 조건을 먼저 확인해 주세요.

Summrizei는 강의 원문을 그대로 복원하지 않고, 구조화된 요약·개념 정리·복습 질문의 형태로만 결과를 만듭니다. 그럼에도 인식한 텍스트와 요약에는 원본 강의의 표현과 자료가 포함될 수 있습니다. 결과물의 공개·판매·재배포 전에 필요한 권한을 확인해야 합니다.

02. 기본 로컬 처리

화면 글자
캡처한 화면은 기기 안에서 PP-OCRv5가 읽습니다. 캡처 이미지는 외부로 전송되지 않습니다.
음성 인식
음성 인식을 켠 경우 Whisper가 기기 안에서 처리합니다. 모델 파일은 처음 사용할 때 내려받습니다.
임시 데이터
캡처 이미지, 인식 텍스트와 노트는 세션 메모리에서 처리하며 저장하지 않습니다. 사용자가 직접 저장한 파일은 기기에 남습니다.

03. 외부 전송이 발생하는 경우

원격 AI 요약에 동의한 경우에만, 영상 제목·재생 시각이 포함된 화면·음성 인식 텍스트와 사용자가 입력한 요약 조건이 요약 제공자에게 전송됩니다. 원본 음성과 캡처 이미지는 어떤 경우에도 전송하지 않으며, 화면 이미지를 외부로 보내는 원격 인식 기능은 제공하지 않습니다.

텍스트 전송도 강의 내용의 외부 처리입니다. 이미지가 전송되지 않더라도 텍스트의 외부 처리가 허용되는지는 강의 제공자의 조건을 확인해 주세요. 외부 전송 없이 쓰려면 원격 요약에 동의하지 않은 상태로 기기 내 인식과 기기 내 요약만 사용하면 됩니다.

제공자와 전송 항목은 개인정보처리방침의 외부 서비스 항목에 기재합니다. 특정 국가에서만 처리된다고 보장하지 않습니다.

04. 이용 범위와 제한

접근할 수 없는 영상이나 캡처가 제한된 콘텐츠는 처리되지 않습니다. Summrizei는 DRM이나 캡처 차단을 우회하지 않으며, 보호 장치가 감지되면 처리를 중단합니다. 기능 제공 자체가 콘텐츠 제공자의 허락을 대신하지 않습니다.

허용 범위
본인이 정당하게 수강 중인 강의를 개인 학습 목적으로 정리하는 데 사용합니다. 생성한 노트를 강의 대체물로 배포·판매하거나, 원본 강의를 복원할 목적으로 사용하는 것은 허용하지 않습니다.
권리 고지
노트를 다른 사람과 공유할 때는 원본 강의의 출처(과목·강사·회차)를 함께 표시하고, 인용 범위를 넘는 사용은 권리자의 허락을 받아야 합니다.
