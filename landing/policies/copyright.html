01. 강의와 노트의 활용

Summrizei는 개인 학습을 돕기 위해 화면 글자와 말소리를 정리하는 도구입니다. 사용하려는 강의의 캡처, 음성 인식, AI 처리와 결과 공유가 허용되는지는 강의 제공자와 사이트의 이용 조건을 먼저 확인해 주세요.

인식한 텍스트나 생성한 요약에 원본 강의의 표현과 자료가 포함될 수 있습니다. 결과물의 공개·판매·재배포 전에 필요한 권한을 확인해야 합니다.

02. 기본 로컬 처리

화면 글자
기본 설정에서는 Tesseract가 캡처 화면을 기기 안에서 읽습니다.
음성 인식
음성 인식을 켠 경우 Whisper가 기기 안에서 처리합니다. 모델 파일은 처음 사용할 때 다운로드될 수 있습니다.
임시 데이터
캡처 이미지, 인식 텍스트와 노트는 패널 세션의 메모리에서 처리합니다. 사용자가 직접 저장한 파일은 기기에 남습니다.

03. 외부 전송이 발생하는 경우

AI 요약을 요청할 때

영상 제목, 재생 시각이 포함된 화면·음성 인식 텍스트, 사용자가 입력한 요약 조건이 선택한 Gemini 또는 Claude API로 전송됩니다. 이 요약 요청에는 원본 음성과 캡처 이미지가 포함되지 않습니다.

원격 화면 인식을 켰을 때

원격 OCR 옵션을 사용하면 캡처 이미지가 선택한 AI 제공자에게 전송됩니다. 기본 로컬 OCR 설정과 데이터 흐름이 달라집니다.

텍스트 전송도 강의 내용의 외부 처리입니다. 이미지가 전송되지 않더라도 텍스트의 외부 처리가 허용되는지는 강의 제공자의 조건을 확인해 주세요.

제공자별 처리 지역·보관기간 등은 개인정보처리방침의 외부 서비스 항목에 기재합니다. 현재 문서는 특정 국가에서만 처리된다고 보장하지 않습니다.

04. 이용 범위와 제한

접근할 수 없는 영상이나 캡처가 제한된 콘텐츠는 처리되지 않을 수 있습니다. Summrizei의 기능 제공 자체가 콘텐츠 제공자의 허락을 대신하지 않습니다.
