SUMMRIZEI / OPEN SOURCE

오픈소스 고지

Summrizei 확장 프로그램과 웹사이트에 포함된 오픈소스 구성 요소를 안내합니다.

01. 확장 프로그램에 포함된 구성 요소

아래 구성 요소는 확장 프로그램 패키지에 그대로 포함되어 배포됩니다. 각 라이선스 원문은 해당 프로젝트의 배포물에 포함된 내용을 기준으로 합니다.

PaddleOCR PP-OCRv5
화면 글자를 기기 안에서 읽습니다. 검출 모델(PP-OCRv5_mobile_det)과 한국어 인식 모델(korean_PP-OCRv5_mobile_rec)을 ONNX로 변환해 포함합니다. Apache License 2.0 · 프로젝트
Transformers.js 4.2.0
브라우저 안에서 음성 인식 모델을 실행합니다. Apache License 2.0 · 프로젝트
ONNX Runtime Web 1.29.0
모델 실행을 위한 WebAssembly 런타임입니다. MIT License · 프로젝트
KaTeX 0.16.11
노트의 수식을 렌더링합니다. 함께 배포되는 KaTeX 글꼴을 포함합니다. MIT License · 프로젝트
marked 15.0.12
노트의 Markdown을 HTML로 변환합니다. MIT License · 프로젝트
Mermaid
노트의 도식을 그립니다. MIT License · 프로젝트

02. 음성 인식 모델

음성 인식 모델은 패키지에 포함하지 않고, 사용자가 음성 인식을 처음 켤 때 Hugging Face에서 내려받아 브라우저 캐시에 저장합니다.

사용 모델
설정에 따라 onnx-community/whisper-small(WebGPU) 또는 Xenova/whisper-base(WebAssembly)를 사용합니다.
원본과 라이선스
두 모델 모두 OpenAI Whisper(MIT License)를 ONNX로 변환한 배포본입니다. 원본 프로젝트
변경 사항
Summrizei는 모델 가중치를 수정하거나 재배포하지 않으며, 배포된 파일을 그대로 내려받아 사용합니다.

03. 웹사이트 구성 요소

markdown-it 15.0.2
랜딩 페이지의 예시 노트를 렌더링합니다. MIT License · 라이선스 원문과 포함 의존성 고지
GSAP 3.15.0 · ScrollTrigger
랜딩 페이지의 스크롤 애니메이션에 사용하며 cdnjs에서 불러옵니다. 배포 조건은 제작사 라이선스를 따릅니다.
글꼴
Hedvig Letters Serif, Geist Mono, IBM Plex Sans KR을 Google Fonts에서 불러옵니다. 모두 SIL Open Font License 1.1입니다.

04. 고지 기준과 문의

대상 버전
확장 프로그램 1.0.0 기준이며, 구성 요소가 바뀌면 이 페이지를 함께 갱신합니다.
라이선스 원문
각 구성 요소의 원문은 위 프로젝트 링크에서 확인할 수 있으며, 확장 프로그램 패키지 안의 배포 파일에도 포함된 고지를 유지합니다.
