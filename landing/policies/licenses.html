SUMMRIZEI / OPEN SOURCE

오픈소스 고지

Summrizei의 화면·음성 인식을 구성하는 프로젝트를 안내합니다.

고지 초안 · 배포 버전 확인 필요

현재 저장소에서 확인되는 주요 구성 요소 목록입니다. 전체 의존성, 배포 버전, 저작권 표시와 라이선스 원문을 확인한 뒤 최종 고지를 게시합니다.

01. 프로그램 구성 요소

Tesseract.js
브라우저에서 화면의 글자를 읽습니다.
작성 필요: 배포 버전 / 저작권 표시 / 라이선스 원문
Tesseract Core
로컬 OCR을 위한 실행 파일과 한국어·영어 언어 데이터를 사용합니다.
작성 필요: Core와 언어 데이터 각각의 버전 / 출처 / 라이선스 원문
Transformers.js
브라우저 안에서 음성 인식 모델을 실행하는 데 사용합니다.
작성 필요: 배포 버전 / 저작권 표시 / 라이선스 원문
ONNX Runtime
모델 실행을 위한 WebAssembly 런타임을 포함합니다.
작성 필요: 배포 버전 / 저작권 표시 / 라이선스 원문

02. 음성 인식 모델

현재 Whisper Tiny 또는 Base 모델을 사용합니다. 프로그램은 설정에 따라 Xenova/whisper-tiny 또는 Xenova/whisper-base 모델 파일을 다운로드합니다.

모델 고지
작성 필요: 원본 모델·변환 모델의 출처, 사용 버전, 라이선스와 저작권 표시
변경 사항
작성 필요: 자체 수정·변환·재배포 여부와 해당 고지

03. 웹사이트와 기타 의존성

랜딩 페이지의 폰트, 아이콘 및 다른 구성 요소도 최종 배포물에 맞춰 고지합니다.

폰트·리소스
작성 필요: 사용 폰트와 리소스의 이름, 제작자, 배포 출처와 라이선스
간접 의존성
작성 필요: 번들에 포함된 간접 의존성의 전체 고지

04. 라이선스 원문과 문의

라이선스 원문과 저작권 고지는 해당 배포 파일에 포함된 내용을 기준으로 정리합니다. 이 초안 목록은 최종 라이선스 고지 전체를 대신하지 않습니다.
