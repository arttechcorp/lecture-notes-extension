결제·환불 안내

현재 결제 여부와 앞으로의 기준을 안내합니다.

01. 현재 결제 여부

Summrizei는 현재 확장 프로그램의 모든 기능을 무료로 제공합니다. 웹사이트와 확장 프로그램에서 결제를 받지 않으며, 카드·계좌 등 결제 수단과 금융 정보를 수집하지 않습니다.

따라서 현재 청구·자동 갱신·해지·환불이 발생하지 않습니다.

02. 사용자가 직접 부담하는 외부 비용

원격 AI 요약을 사용하려면 사용자가 OpenRouter에서 직접 발급한 API 키를 입력해야 합니다. 이때 발생하는 사용료는 사용자와 OpenRouter 사이의 거래이며, 결제·환불도 해당 서비스의 정책을 따릅니다. Summrizei는 이 금액을 대신 청구하거나 환불하지 않습니다.

비용 없이 사용하려면 기기 내 인식과 기기 내 요약 기능만 사용하면 됩니다.

03. 유료 플랜을 도입하는 경우

유료 플랜을 시작하게 되면 아래 내용을 이 페이지에 먼저 게시하고, 시행일을 명시한 뒤 적용합니다.

  • 플랜별 금액, 통화, 세금 포함 여부와 결제 주기
  • 자동 갱신 여부와 다음 결제일 안내 방식
  • 월 제공량의 정의와 처리 실패·재시도 시의 차감 기준
  • 해지 경로와 적용 시점
  • 환불 요청 기간·대상·산정 방식과 처리 일정

결제를 도입하기 전에는 위 조건이 존재하지 않으므로, 어떠한 청구도 발생하지 않습니다.
