# 강의 필기 도우미

강의 영상 화면을 캡처·OCR해서 **타임스탬프가 붙은 마크다운 학습 노트**를 만들어주는 크롬 확장 프로그램(Manifest V3). 클로바노트의 화면 버전에 가깝습니다.

특정 LMS에 묶여 있지 않습니다. 표준 `<video>` 요소만 찾으면 되므로 런어스·무들·유튜브 등 사이트를 가리지 않습니다.

> 개인 학습용 도구입니다. 강의 영상의 캡처·재배포는 학칙이나 저작권 정책에 저촉될 수 있으니 결과물을 외부에 공유하지 마세요. 노트는 OCR 기반 자동 생성물이라 오독이 섞일 수 있습니다.

## 동작 방식

1. 사이드패널에서 강의 영상이 열린 탭을 고릅니다. (`toolbar=no` 팝업 창으로 뜬 영상도 목록에 잡힙니다.)
2. 해당 사이트 접근 권한을 그 자리에서 승인받고, `chrome.scripting`으로 캡처 스크립트를 주입합니다. 설치 시점에 전 사이트 권한을 요구하지 않습니다.
3. **preflight** — 프레임 1장을 시험 캡처해 CORS 차단·DRM 여부를 먼저 판정하고, 안 되면 이유를 명시하고 중단합니다.
4. 화면이 바뀔 때만(저해상도 그레이스케일 diff) 프레임을 잡고 `video.currentTime`을 함께 기록합니다.
5. 프레임을 묶어 Claude Vision으로 OCR하고, 중복 줄은 로컬에서 병합합니다.
6. 전체 스크립트로 마크다운 노트(개요 / 목차 / 핵심 개념 / 섹션별 정리 / 확인 필요)를 생성합니다.

## 캡처 모드

| 모드 | 영역 | 간격 | 용도 |
| --- | --- | --- | --- |
| **슬라이드** (기본) | 전체 화면, 가로 1024px로 축소 | 5초 | 대부분의 강의. 슬라이드는 1~2분마다 바뀌므로 프레임 수가 적어 저렴합니다. |
| 자막 띠 | 하단 20%, 원본 해상도 | 2초 | 화면에 자막이 박혀 있는 강의 |

배속 재생 시 캡처 간격을 재생 속도에 비례해 줄입니다.

## 설치

1. `chrome://extensions` → "개발자 모드" 켜기
2. "압축해제된 확장 프로그램을 로드" → 이 폴더(`lecture-notes`) 선택
3. 확장 아이콘 우클릭 → 옵션 → 본인 소유의 Claude API 키 입력 (console.anthropic.com 발급, 브라우저 로컬에만 저장)

## 사용

1. 강의 영상을 재생
2. 확장 아이콘 클릭 → 사이드패널 → 탭 선택 → 캡처 모드 선택 → "캡처 시작"
3. 영상이 끝나면 노트가 생성됩니다. 복사하거나 `.md`로 저장하세요.

OCR 결과는 배치마다 자동 저장되므로 영상을 끝까지 안 보거나 창을 닫아도 이미 캡처한 분량은 남습니다. "노트 생성" 버튼으로 재캡처 없이 노트만 다시 만들 수 있습니다(OCR 비용 없음).

## 알려진 한계

| 장벽 | 증상 | 상태 |
| --- | --- | --- |
| CORS 미설정 CDN | 프레임 캡처 자체가 차단 | preflight가 감지·안내, 우회 불가 |
| DRM (Widevine/EME) | 캔버스가 검은 프레임 반환 | preflight가 감지·안내, 우회 불가 |
| cross-origin iframe 플레이어 | `<video>`를 못 찾음 | `allFrames` 주입으로 상당수 커버, 일부는 실패 |
| 슬라이드 없이 말로만 하는 강의 | OCR할 텍스트가 없음 | 오디오 전사(v2)로만 해결 가능 |

그 외: 스크립트가 30,000자를 넘으면 앞부분만 요약하고 노트 끝에 그 사실을 명시합니다. OCR 오독은 노트의 "확인 필요" 섹션에 모입니다.

## 비용

60분 강의·슬라이드 30장 기준 대략 OCR 33K 입력 토큰(haiku) + 노트 수 K(sonnet). 사이드패널에 OCR/노트 토큰이 따로 표시되므로 실제 사용량을 바로 확인할 수 있습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | MV3 설정. `content_scripts` 없음 — 주입은 런타임에 |
| `content.js` | preflight·프레임 캡처·diff·타임스탬프·배치 전송 (executeScript로 주입) |
| `lib/mergeLines.js` | OCR 결과 zip·중복 병합 (`node lib/mergeLines.test.js`로 단독 테스트) |
| `background.js` | Claude API 호출 (OCR: haiku / 노트: sonnet), 토큰 사용량 브로드캐스트 |
| `sidepanel.html` / `.js` | 탭 선택·모드 선택·진행 상태·결과 내보내기 |
| `options.html` / `.js` | API 키 입력·저장 |

## v2 후보 (미구현)

`content.js` → `background.js` 계약은 `{ frames, times }` → `{ lines }` 하나뿐입니다. 같은 형태의 결과를 만드는 경로를 추가하면 노트 생성과 UI는 손대지 않고 입력 소스를 바꿀 수 있습니다.

① `video.textTracks` / WebVTT 스니핑으로 진짜 자막 공짜 추출 ② `chrome.tabCapture` 오디오 → 전사 API (타사 키 필요) ③ 긴 강의 청킹 요약 ④ 영상별 스크립트 분리 저장
