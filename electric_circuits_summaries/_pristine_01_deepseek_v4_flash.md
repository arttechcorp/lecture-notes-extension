## 📌 [시험 전 최우선 요약]

1. **반도체 정의**: 전도체와 절연체 사이의 중간 저항률(resistivity)을 갖는 물질
2. **에너지 밴드 갭(Eg)**: Silicon ≈ 1.1 eV (전자 볼트) → Si 선호 이유
3. **밴드(Band)**: 고체 내 전자가 점유 가능한 허용 에너지 상태들의 집합
4. **전도대(Conduction Band)**: 높은 에너지, 전자가 자유롭게 이동 가능
5. **원자가대(Valence Band)**: 낮은 에너지, 전자가 완전히 점유
6. **트랜지스터 정의**: 저항을 변조(modulate)할 수 있는 소자 = Transfer + Resistor
7. **Si 원자 구조**: 3s²3p² 전자가 SP³ 혼성 오비탈 형성 → 4개의 결합 생성
8. **정공(Hole)**: 전자가 결합에서 이탈 시 생성되는 빈자리
9. **항복 전압(Breakdown Voltage)**: Si가 Ge보다 높음 → 높은 신뢰성
10. **결정질 반도체**: IC 제작에 필수 (전자 거동 예측 가능)

## 2. 에너지 밴드 이론

### 2.1 밴드(Band)의 정의
- **정의**: 고체 내 전자가 점유할 수 있는 허용 에너지 상태들의 집합
- **에너지 상태(Energy State)**: 전자가 이용 가능한 상태

### 2.2 에너지 밴드 구조 비교





| 물질 유형 | 밴드 갭 크기 | 전도 특성 |
|-----------|-------------|-----------|
| 절연체(Insulator) | 매우 큼(Huge) | 전도 어려움 |
| 반도체(Semiconductor) | 중간 (~1.1 eV) | 제어 가능한 전도 |
| 전도체(Conductor) | 없음(0) | 자유 전도 |

### 2.3 전자의 구속 상태
- **원자핵 근접 전자**: 인력(Attraction force) > 반발력 → 강하게 결속
- **원자핵 원거리 전자**: 인력 ≈ 반발력 (평형) → 약하게 결속
- **원자가대(VB)**: 전자가 완전히 점유 (Full)
- **전도대(CB)**: 초기 전자 없음 → 전류 흐름 없음

### 2.4 전도 메커니즘
- 외부 에너지 인가 → 원자가대 전자가 전도대로 이동
- 전도대에서 전자는 자유롭게 이동 가능 → 전류 흐름 발생
- **절연체**: 밴드 갭이 매우 커서 전도 어려움
- **전도체**: 밴드 갭 없음 → 항상 전도 가능

## 3. 반도체 물성 (Property of Semiconductor)

### 3.1 저항률(Resistivity) 기준 분류

| 구분 | 저항률 |
|------|--------|
| 전도체(Conductor) | 낮음 (Low) |
| 절연체(Insulator) | 높음 (High) |
| 반도체(Semiconductor) | 중간 (Intermediate) |

### 3.2 결정 구조

```
단결정(Crystalline)  다결정(Polycrystalline)  비정질(Amorphous)
   [규칙적 배열]       [결정립 + 결정립계]        [불규칙 배열]
```

- **결정(Crystal)**: 원자가 잘 조직된 구조
- **다결정**: 여러 결정 구조가 결합 (경계 = 결정립계, Grain Boundary)
- **결정립계(Grain Boundary)**: 서로 다른 결정립(grain) 사이의 경계

### 3.3 결정 구조의 중요성
- **IC 제작 필수 조건**: 단결정 실리콘 필요
- **최신 기술**: 수 나노미터(nm) 수준 (수십 nm 이하)
- **비정질 실리콘 문제**: 원자 배열 불규칙 → 전자 거동 예측 불가능
- **예외**: 최근 비정질 반도체도 상업적으로 중요해짐

---

## 4. 반도체 재료 분류

### 4.1 주기율표 기준 분류 (전기공학 관점)

| 족(Group) | 원소 | 특징 |
|-----------|------|------|
| 4족 (대표) | Si, Ge | 단일 원소 반도체 |
| 3족 | (화합물 구성) | 3-5족 화합물 반도체 (예: GaAs) |
| 5족 | (화합물 구성) | 3-5족 화합물 반도체 |
| 2족 | (화합물 구성) | 2-6족 화합물 반도체 |
| 6족 | (화합물 구성) | 2-6족 화합물 반도체 |

> **참고**: 현대 화학에서는 '14족'이지만, 반도체 산업에서는 '4족'으로 표기 (전기공학 관례)

### 4.2 주요 반도체 재료

| 재료 | 용도/특징 |
|------|-----------|
| **Silicon (Si)** | 대표적 반도체, 현대 반도체 산업의 주축 |
| **Germanium (Ge)** | 최초 트랜지스터에 사용, 이후 문제로 Si로 대체 |
| **GaAs** | SpaceX 위성 태양전지(고성능 솔라셀)에 사용 |
| **Carbon (C)** | 논란 있음 → 수업에서 제외 |

### 4.3 Silicon vs Germanium (Si 선호 이유)

| 비교 항목 | Silicon (Si) | Germanium (Ge) |
|-----------|--------------|----------------|
| **밴드 갭** | 더 큼 (안정적 제어) | 작음 |
| **전류 제어** | 용이 | 어려움 (항복 쉽게 발생) |
| **가격** | 저렴 | 비쌈 |
| **항복 전압** | 높음 (신뢰성 ↑) | 낮음 |

> **핵심**: Si는 밴드 갭이 더 커서 전류 제어가 용이하고, 온도 변화에 따른 누설 전류가 적음

## 5. 트랜지스터의 의미

### 5.1 어원
- **Transfer(전달) + Resistor(저항)** = Transistor
- **정의**: 자체 저항을 변조(modulate)할 수 있는 소자

### 5.2 동작 원리
- I-V 곡선에서 기울기(저항)가 인가 전압에 따라 변화
- 스위치 역할: On/Off 상태를 명확히 정의 가능

### 5.3 반도체의 중요성
- 트랜지스터, 다이오드 = 스위치로 사용
- 스위치의 On/Off 명확성이 핵심 → 온도 영향 최소화 필요
- **온도 영향**: 높은 온도에서 Si는 열적으로 여기된 전자로 인해 누설 전류 발생 가능

## 6. SiO₂ (실리콘 산화막)

- **특성**: 절연체(Insulator)
- **용도**: 커패시터(Capacitor) 제작 → 트랜지스터 구현의 핵심
- **재료 가치**: Si 단독만으로도 유용한 소자 제작 가능 (SiO₂ 형성 용이)

---

## 7. 실리콘 원자 구조와 SP³ 혼성 오비탈

### 7.1 전자 배치
- **Si 원자**: 원자번호 14
- **전자 배치**: 1s² 2s² 2p⁶ 3s² 3p²

```
핵(Nucleus)
  ┌─ 1s² (내부 껍질)
  ├─ 2s² 2p⁶ (내부 껍질)
  └─ 3s² 3p² (최외각 전자 4개) ← 원자핵에서 멀리 떨어짐
```

### 7.2 SP³ 혼성 오비탈의 형성
- **3s²와 3p² 에너지 준위**: 거의 동일 (에너지 차이 미미)
- **결과**: 4개의 동일한 에너지 상태 = SP³ 혼성 오비탈
- **특징**: 최외각 전자가 원자핵에서 멀리 떨어져 있어 약한 결속력

### 7.3 실리콘 격자 구조

```
Si ─ Si ─ Si     (단일 결정 실리콘)
 │    │    │
Si ─ Si ─ Si     (4면체 결합 구조)
 │    │    │
Si ─ Si ─ Si
```

- 각 Si 원자는 4개의 Si 원자와 공유결합 형성
- 결합선 = 공유 결합 (SPS 혼성 오비탈)
- 모든 원자 결합 시: 고체(Solid) 형성

---

## 8. 전자-정공 쌍 생성

### 8.1 에너지 인가 과정
1. Si 원자들은 결합 형성 → 고체 상태
2. 외부 에너지(열, 빛 등) 인가
3. 결합에서 전자가 이탈

### 8.2 생성 과정 전개





- **자유 전자**: Si 격자 내에서 자유롭게 이동 가능
- **정공(Hole)**: 전자가 이탈한 빈자리 → 양전하 띈 입자처럼 동작

> **핵심 규칙**: 전자 생성 시 항상 정공도 함께 생성 (쌍 생성, Pair Generation)

## 9. 시험 예상 핵심 질문

1. **"왜 Silicon이 Germanium보다 선호되는가?"**
   - 밴드 갭이 더 큼 → 전류 제어 용이
   - 저렴한 가격
   - 높은 항복 전압 (신뢰성)

2. **"트랜지스터의 정의는?"**
   - 저항을 변조할 수 있는 소자 (Transfer + Resistor)

3. **"밴드(Band)란?"**
   - 고체 내 전자가 점유 가능한 허용 에너지 상태들의 집합

4. **"정공(Hole)이란?"**
   - 전자가 결합에서 이탈할 때 생성되는 빈자리 (항상 전자와 쌍으로 생성)

5. **"왜 단결정 실리콘이 필요한가?"**
   - 비정질이면 전자 거동 예측 불가 → IC 제작 불가

6. **"Si의 밴드 갭 값은?"**
   - 약 1.1 eV (전자 볼트)
