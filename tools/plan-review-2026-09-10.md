- **미국 서버 보장**, **강의 한 편 원가 7원/13원/26원 보장**, **사업 마진 90% 보장**은 현재 증거로 쓸 수 없다.
- 계정·플랜별 사용량 제한·운영자 API 서버·Paddle 결제가 연결되기 전에는 유료 기능이 지금 작동하는 것처럼 판매하지 않는다. 결제 연결값은 비워 두고 준비 상태를 명확히 표시한다.

각 플랜 예시는 이 비교 파일을 근거로 발췌·편집하되 **동일 강의 입력 기반 예시**임을 표시한다. 원본의 NPV 사례는 반올림된 숫자다. A의 정확한 1년 NPV는 약 3,636만원, B는 약 1억 8,182만원이므로 기존의 3,600만원·1.8억원을 사용할 때는 `약`을 붙인다. 실제 외부 강의를 검증·시청했다고 표현하지 않는다.

## OCR 한 편 7원은 아직 가정

Qwen-VL은 모델군 이름이며 프레임 수·해상도·이미지 토큰화·출력 글자 수가 정해져야 가격을 계산할 수 있다. 계산식은 다음과 같다.

`원가(원) = 1,450 × Σ[(입력 토큰 × 입력 단가 + 출력 토큰 × 출력 단가) / 1,000,000]`

예를 들어 **슬라이드마다 입력 1,000 / 출력 200 토큰**이라고 가정하면:

| 슬라이드 수 | OpenRouter $0.104/$0.416 가정 | Alibaba International $0.16/$0.64 가정 |
|---|---:|---:|
| 20장 | 5.43원 | 8.35원 |
| 30장 | 8.14원 | 12.53원 |
| 40장 | 10.86원 | 16.70원 |

이는 비용 민감도를 설명하는 산술 예시이며 실제 캡처 측정치가 아니다. 텍스트가 많은 슬라이드, 자막 모드의 잦은 캡처, 중복 프레임, 재시도, 수식/표 출력은 비용을 늘릴 수 있다. 중복 제거와 강의당 프레임·길이 한도를 구현한 뒤 다양한 강의에서 측정해야 한다.

## Free와 처리 지역

Tesseract와 Whisper를 사용자 기기에서 실행하고 타임라인을 로컬에서 조합하면 **외부 추론 API 호출 비용은 0원**으로 설계할 수 있다. 그러나 사용자의 CPU·메모리·전력 및 초기 모델 다운로드가 필요하고 서비스 배포·업데이트·지원 비용까지 0원이 되는 것은 아니다. UI에는 `무료`, `내 기기에서 인식`, `원문 타임라인`처럼 사용자 기준 표현을 사용한다. `사양 제약 없음`·`무조건 즉시 실행`은 피한다.

**Haiku 4.5를 쓴다는 이유만으로 미국 서버가 보장되지는 않는다.** Anthropic의 기본 추론 지역은 global이다. 현재 문서에서 `inference_geo`는 Claude 4.6 이후 모델에만 지원되므로 Haiku 4.5에 해당 매개변수를 붙이는 방법은 사용할 수 없다. Haiku는 Bedrock/Google Cloud의 미국 지역 엔드포인트 등 별도 선택과 계약 확인이 필요하다. 지역/다중 지역 엔드포인트에는 가격 가산이 있을 수 있다.

또한 노트 요약을 미국에서 처리해도 **앞단 Qwen OCR의 이미지 처리 지역, 라우터, 애플리케이션 서버, 저장·로그 지역**까지 미국으로 제한되는 것은 아니다. 전체 경로를 고정하고 검증하기 전에는 미국 서버 보장 문구를 넣지 않는다.
