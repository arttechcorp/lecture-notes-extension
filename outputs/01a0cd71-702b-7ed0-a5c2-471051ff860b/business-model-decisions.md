# 강의 요약 서비스 BM 결정사항

작성일: 2026-09-26

이 문서는 이 대화의 결정사항과 [최신 사업모델 엑셀](./lecture-summary-business-model-current.xlsx)을 기준으로 작성했다. 일반 무료체험 폐지, 피추천인 체험 및 유료 요금제 한도를 문서와 엑셀에 함께 반영했다. 외부 요금은 기존 엑셀에 기록된 조사 시점의 계획값이며, 이번 변경에서 최신 요금으로 다시 조사한 값은 아니다.

**최신 정책(2026-09-26): Essential / EDU 월 400분, Pro 월 600분. 일반 무료체험은 폐지하고 피추천인에게만 14일·누적 최대 200분 체험을 제공한다.** 엑셀의 일반 가입자는 체험 없이 당월 직접 결제하는 경로로 변경했다. 직접 유료 전환율 15%는 계산을 위한 임시 비교값이며, 사용자가 확정한 전환율이나 실측치가 아니다.

## 1. 문서의 기준

- **결정사항**: 사용자가 직접 정한 정책과, 사용자가 수정한 최신 엑셀의 상품 조건.
- **모델 가정**: 매출·비용 계산을 위해 입력한 전환율, 사용량, 비용 및 계산상의 단순화. 서비스 약관이나 운영 정책으로 확정된 내용은 아니다.
- **확인 필요**: 대화와 모델 사이에 해석 차이가 있거나 아직 명확하게 정하지 않은 조건.

이전 대화보다 최신 사용자 수정값을 우선한다. 실제 서비스에 해당 정책이 구현·배포됐는지는 이 문서의 검증 범위에 포함하지 않았다.

## 2. 고객과 제공 가치

주 고객은 온라인 강의 또는 실시간 강의를 수강하는 학생이다. 강의 진도가 빨라 내용을 이해하기 어렵고, 시험 준비와 복습을 위한 요약 노트가 필요한 상황을 해결한다.

제품의 핵심 가치는 **강의 화면과 음성을 바탕으로 요약 노트를 만들고, PDF로 복습할 수 있게 하는 것**이다. 제품 소개 영상과 랜딩페이지에서는 노트의 세부 내용보다 다음 사용 흐름을 먼저 이해시키는 방향을 채택했다.

> 강의 수강 → 한 번의 시작 조작 → 강의 화면·음성 인식 → 요약 노트 생성 → 요약노트.pdf → 복습

이는 제품 가치와 설명 방향이며, 각 요금제의 구체적인 기능·사용 한도를 확정한 표는 아니다.

## 4. 피추천인 전용 무료체험과 사전예약

### 일반 가입자

일반 가입자에게 Essential / EDU 무료체험을 제공하지 않는다. Free 요금제는 유지하며, 유료 기능을 이용하려는 일반 가입자는 유료 구독으로 전환한다. Essential / EDU 유료 요금제 자체를 없애는 변경은 아니다.

### 피추천인 전용 무료체험

| 항목 | 현재 기준 |
| --- | --- |
| 대상 | 추천 코드로 가입한 피추천인 |
| 기간 | 14일 |
| 누적 이용량 상한 | 200분 |
| 제공 기능 | Essential / EDU의 모든 기능 |
| 시작 조건 | 추천 코드 적용 및 자동결제 카드 등록 |
| 혜택 제공 캠페인 | 기존 추천 캠페인과 동일하게 출시 첫 두 달 |

체험 상한은 초기 200분에서 엑셀 수정 시 150분으로 바뀌었고, 최신 요청에 따라 **피추천인 14일 전체 누적 200분**으로 확정했다. Essential / EDU 유료 월 한도 400분과 구분한다.

일반 가입자에게 제공하던 체험을 피추천인의 가입 혜택으로 이전한다. 캠페인 종료 직전 발급한 코드의 사용 마감과 체험 시작 기한은 별도 확정이 필요하다.

### 사전예약 혜택

- 사전예약 고객에게 **첫 달 무료** 혜택을 제공한다.
- 혜택 시작 조건은 **자동결제 카드 등록**이다.
- 무료 기간이 끝난 뒤 유료 구독으로 전환하는 구조를 계획한다.
- 적용 가능한 요금제, 무료 첫 달의 정확한 이용량 상한, 첫 결제일과 취소·환불 조건은 별도 확정이 필요하다.

현재 엑셀은 사전예약 첫 달 무료와 피추천인 14일 체험을 중복하지 않으며, 무료 기간 종료 다음 달에 유료 전환이 발생하는 것으로 단순화한다. 사전예약자가 추천 코드도 적용한 경우의 실제 중복 혜택 여부와 결제일은 별도 확정이 필요하다.

근거: `Assumptions!C9:C10`, `C12`, `C17`, `C26`; `Overview!F25:F26`.

## 5. 레퍼럴 정책

### 채택한 방향

1. 사전예약자에게 추천 코드 2개를 발급한다.
2. 자신의 코드로 2명을 유치하면 추천인에게 무료 이용 1개월을 추가 제공한다.
3. 추천으로 들어온 고객에게도 동일하게 자신의 코드로 2명을 추천할 기회를 제공한다.
4. 후속 추천 고객의 인정 조건은 **무료체험 시작 및 자동결제 카드 등록**이다.
5. 추천 캠페인은 **출시 후 첫 두 달에만 운영**한다.

추천인과 피추천인의 혜택을 구분한다.

| 수혜자 | 혜택 | 조건 |
| --- | --- | --- |
| 추천인 | 추가 무료 이용 1개월 | 본인 코드로 2명 유치 및 추천 인정 조건 충족 |
| 피추천인 | Essential / EDU 전체 기능 14일·최대 200분 무료체험 | 추천 코드 가입 및 자동결제 카드 등록 |

피추천인이 이후 다른 사람을 추천하면 본인의 추천인 보상도 얻을 수 있다. 피추천인에게 제공하는 체험은 추가 무료월 보상과 별개의 혜택이다.

### 현재 엑셀의 계산 방식

| 항목 | 모델 처리 |
| --- | --- |
| 캠페인 기간 | 출시 M1~M2 |
| M1 추천 주체 | 카드 등록을 완료한 사전예약 고객 중 코드 공유자 |
| M2 추천 주체 | M1에 추천으로 들어와 카드 체험을 시작한 고객 중 코드 공유자 |
| M3 이후 신규 추천 가입 | 0명 |
| 보상 자격 | 동일 추천인의 코드 2개 모두 가입·카드 체험 조건을 충족 |
| 보상 사용 시점 | 획득 다음 달. M2 획득 보상은 M3에도 비용·매출에 반영 |
| 보상 사용률 | 다음 달 70% 사용 가정 |
| 미사용분 | 만료로 단순화 |
| 보상 대상 한도 | 해당 월 유료 고객 수 이내로 적용 |
| 오가닉 고객의 코드 발급 | 모델에서는 제외 |

추천 신규 가입과 보상은 서로 다른 계산이다. 서로 다른 추천인이 각각 한 명씩 유치한 경우, 이를 합쳐 무료월 한 개를 지급하지 않는다.

```text
코드 공유자 = 해당 세대의 추천 자격자 × 코드 공유율
추천 신규 가입 = 코드 공유자 × 2개 × 코드별 가입률
추천 카드 체험자 = 추천 신규 가입 × 카드 체험 전환율
무료월 획득자 기대값 = 코드 공유자 × (코드별 가입률 × 카드 체험 전환율)²
```

### 정책으로 확정해야 할 부분

- 최초 제안의 사전예약자 보상 조건은 “2명 회원가입”이었고, 후속 추천은 “2명 카드 등록 체험”이었다. 엑셀은 **모든 추천 단계에 카드 체험 조건을 통일**했다. 실제 정책도 통일할지는 확인이 필요하다.
- 추천 보상 사용 기한과 미사용분 만료는 모델 가정이다. 사용자에게 안내할 만료 정책은 아직 확정하지 않았다.
- 캠페인 종료 직전에 발급한 코드의 사용 마감, 두 명 중 한 명만 조건을 충족한 경우, 취소·중복 계정·부정 추천 처리 기준은 미정이다.
- 개인별 코드 재발급과 반복 보상은 모델에 없다. 현재는 2개 코드가 모두 인정되면 1회 보상을 얻는 구조다.
- M1 사전예약자 → M2 추천 유입자의 순차 공유는 월간 모델의 단순화다. 실제로 가입 즉시 코드를 발급할지, 사전예약자가 M2에도 계속 공유할 수 있을지는 별도 운영 결정이 필요하다.

근거: `Assumptions!C11:C13`, `C21:C23`, `C36`, `C74`; `Monthly Model` 10~12행, 43~44행.

## 6. 유입·전환·리텐션의 기본 가정

24개월을 월 단위로 모델링한다. 일반 가입자는 가입 당월 직접 결제하거나 Free로 남는 것으로 계산한다. 기존 Free 고객의 이후 유료 전환은 별도로 모델링하지 않았다. 직접 결제 전환율은 실측 전이므로 이전 합산 전환율 15%를 비교용 시작값으로 넣었으며, `Assumptions!C102`에서 조절한다.

| 항목 | 현재 값 |
| --- | ---: |
| 출시 시 사전예약 명단 | 25명 |
| 사전예약 → 실제 계정 가입 | 60% |
| 사전예약 가입 → 카드 등록 | 70% |
| 사전예약 무료 첫 달 → 유료 전환 | 40% |
| 첫 달 오가닉 가입 | 20명 |
| 오가닉 월 성장률 | 5% |
| 오가닉 가입 → 카드 체험 (폐지된 경로의 이전 가정) | 60% |
| 오가닉 카드 체험 → 유료 전환 (폐지된 경로의 이전 가정) | 25% |
| 일반 신규 가입 → 당월 직접 유료 구독 | 15%, 임시 비교 가정 |
| 추천 자격자 중 두 코드 공유 | 20% |
| 각 초대 코드 수신 → 가입 | 30% |
| 추천 가입 → 카드 체험 | 70% |
| 추천 카드 체험 → 유료 전환 | 25% |
| 모든 유료 요금제의 월 이탈률 | 6.4% |
| Free의 월 비활성 이탈률 | 30% |
| 유료 이탈자 중 Free 잔류 | 30% |
| 신규 유료 구성: Essential / EDU / Pro | 40% / 45% / 15% |
| 학사시즌 계수 | 현재 12개월 모두 1 |

기존 엑셀의 오가닉 가입 → 유료 전환 단순 곱은 **60% × 25% = 15%**였다. 이 비율을 새 직접 결제 경로의 임시 비교값으로만 사용한다. 무료체험을 없애도 전환율이 유지된다는 근거는 없으며, 확정 정책으로 채택한 수치가 아니다. 이전 60%·25% 입력은 변경 이력 보존을 위해 남겼지만 계산에는 사용하지 않는다. 추천 가입 → 유료 전환 가정은 **70% × 25% = 17.5%**이며, 피추천인 체험 종료 후 전환을 계산한다.

벤치마크는 본 서비스의 실측치가 아니다. 타 서비스의 6개월 전환율과 이 모델의 월간 카드 체험 전환율은 정의와 기간이 달라 직접 비교할 수 없다. 방학·시험 기간에 따른 유지율 변화도 현재 별도로 반영하지 않았다.

근거: `Assumptions!C15:C36`, `G6:R6`, `C102`.

## 7. 비용 구조

### 운영 원칙

- 현재 직원은 없으며, 인건비는 **월 0원**이다.
- LLM API 호출량에 따라 비용이 증가하는 변동비 중심 구조로 모델링한다.

| 선택형 비전 엔진 비중 / 분당 비용 | 0% / 0원, 실측 전 미반영 |

```text
외부 요약 강의량 = (유료 이용량 + 피추천인 체험 이용량 + 사전예약 무료월 이용량) × 외부 AI 요약 비중
입력 토큰 = 외부 요약 강의량 × 분당 입력 토큰 × 부가 호출 배수
출력 토큰 = 외부 요약 강의량 × 분당 출력 토큰 × 부가 호출 배수
API 원가 = (입력 토큰 × 혼합 입력 단가 + 출력 토큰 × 혼합 출력 단가) ÷ 1,000,000 × 환율
충전 수수료 = API 원가 × 5.5%
```

엑셀에서 일반 오가닉 체험 이용량을 제거했다. 유료 비용은 요금제별 `MIN(평균 사용량, 월 한도)`로 계산한다. 기존 평균 가정인 Essential / EDU 200분, Pro 400분은 유지하므로, 한도를 늘렸다는 이유만으로 모든 고객이 한도를 소진한다고 가정하지 않는다. 사전예약 무료월에도 요금제 구성별 월 한도를 적용한다.

모델상 음성 인식은 기기 내에서 처리하며, 외부 AI 요약 비용은 동의한 텍스트 추론 기준이다. 비전 엔진을 활성화하면 현재 0원인 비전 원가를 별도로 측정·반영해야 한다. 0원이 실제 무원가를 의미하지 않는다.

### Vercel

사용량이 작다는 이유만으로 상업 서비스에 Hobby를 적용하지 않는다. 기존 조사에서 Hobby의 개인·비상업적 사용 조건을 확인했으므로, 현재 모델의 기본값은 **Pro 월 $20, 계획 환율 기준 28,000원**이다.

- `Hobby 사용 자격` 레버는 기본 0이다. 비상업 파일럿처럼 자격이 있는 경우에만 1을 적용한다.
- 랜딩 방문자 수는 신규 가입자 수 ÷ 방문자 가입률로 근사한다. 현재 가입률 5%, 방문자당 요청 8건, 전송량 2MB를 가정한다.
- Pro 포함량은 전송 1TB(모델상 1,024GB), Edge 요청 1,000만 건이다.
- 초과 전송 $0.35/GB, 초과 Edge 요청 $3.20/100만 건을 계획 단가로 둔다.
- Pro 기본료에 포함된 $20 사용량 크레딧을 종량 비용에서 차감한다.
- 모델은 랜딩 트래픽 중심이다. 별도 API 서버·다른 Vercel 기능의 실제 비용은 추가 측정해야 한다.

## 8. 매출과 순이익 계산

```text
기말 유료 고객 = 기초 유료 고객 - 당월 이탈 + 신규 유료 전환
고객 결제액 = 유료 서비스 정가 총액 - 사전예약 할인 - 추천 무료월 할인
순매출 = 고객 결제액 ÷ 1.1
전체 영업비용 = API + 충전 수수료 + 비전 + Vercel + Supabase + PG + 고객 지원 + 마케팅 + 인건비 + 기타 판관비
세전 이익 = 순매출 - 전체 영업비용
추정 순이익 = 세전 이익 - 이월결손금을 단순 적용한 추정 법인세
```

사전예약·추천 무료월은 매출 할인으로 처리한다. 무료 기간에도 사용량에 따른 API·지원·인프라 비용이 발생한다. 계산한 순이익은 현금흐름과 다르며, 결제 정산 지연·선불 API 충전·환불·차입·투자금 등을 모두 반영한 자금계획이 아니다.

## 9. 최신 정책을 반영한 엑셀 전망

아래는 피추천인 전용 체험, 요금제별 한도, 일반 가입 당월 직접 결제를 반영해 재계산한 계획 시나리오다. **직접 결제 전환율 15%라는 미검증 비교값에 의존**하며, 정책 변경으로 이 매출이 보장되거나 실제 수익성이 개선됐다는 의미는 아니다. 고객 수의 소수점은 확률을 적용한 기대값을 뜻한다.

## 10. 모델 사용 시 주의할 불일치와 미확정 사항

1. **직접 결제 전환율**: 일반 체험 폐지와 직접 결제 경로는 엑셀에 반영했다. 신규 일반 가입자의 당월 결제율 15%는 임시값이며 실측이 필요하다. Free 가입 이후 지연 전환을 반영하려면 추가 가정이 필요하다.
2. **체험 및 사용량 설명 정리**: 피추천인 14일·200분, Essential / EDU 월 400분, Pro 월 600분으로 설명과 산식을 맞췄다. 평균 사용량은 별도의 추정값으로 유지한다.
3. **추천 운영기간 레버**: 기본값은 2개월이다. M1·M2를 포함한 모든 월의 코드 공유자 수식을 운영기간 레버에 연결했다.
4. **상품 기능·초과 사용**: Free의 한도, Pro의 한도 외 차별 기능, 유료 한도 초과 시 차단·추가 구매·업그레이드 방식은 미정이다.
5. **학생가 운영**: 학생 인증 방식·갱신 주기·자격 상실 시 가격 전환은 미정이다.
6. **체험·사전예약 조건**: 피추천인 체험과 사전예약 무료월의 중복 여부, 사전예약 혜택 대상 플랜, 종료·취소·환불 조건은 별도 확정이 필요하다.
7. **추천 조건**: 모든 단계에서 카드 체험을 요구할지, 만료·캠페인 종료 후 사용·반복 보상·부정 사용 처리 기준을 확정해야 한다.
8. **실측 우선순위**: 채널별 가입과 카드 등록, 체험 종료 후 첫 결제, 월 이탈, 요금제별 강의 이용량·토큰·API 청구액, 인프라 사용량을 측정해 가정을 교체한다.
